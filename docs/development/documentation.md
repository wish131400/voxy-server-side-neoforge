# 文档维护约定

[文档目录](../README.md)

本仓库维护 NeoForge 1.21.1 文档。涉及其他加载器时标明平台与实际验证版本，不能把共享代码同步写成另一平台已通过实测。

| 内容 | 位置 | 维护方式 |
| --- | --- | --- |
| 项目简介与安装入口 | 根目录 `README.md` | 保持简短，链接到专题说明 |
| 配置、命令、缓存与升级 | `docs/user-guide/` | 描述当前版本行为，删除失效选项 |
| 依赖与模组兼容 | `docs/compatibility/` | 固定游戏、加载器、实际文件或源码提交；区分接口与实机验证 |
| 架构、公开接口与构建 | `docs/development/` | 随代码边界更新 |
| 旧发布、采样、实验与阶段验收 | `docs/history/` | 标明时间、输入、构建身份与未测范围，不当作当前保证 |
| 工具使用说明 | 对应 `tools/` 目录 | 和可执行脚本、fixture 一起维护；历史实验明确标注 |

新增报告放入对应历史分类，并更新分类索引。工具实验的说明可保留在脚本旁，通过 [实验工具索引](prediction-experiments.md)查找。只保留一份当前说明，其他页面通过相对链接引用；改名或移动文档时检查所有入链。供工具写入或证据清单引用的历史报告可以保留原路径，在历史索引登记。

仓库文档使用可移植相对路径；本机运行目录、下载依赖、临时采样和个人环境路径不纳入公开说明。README 和更新日志不堆叠每轮试验的命令与统计，详细证据留在历史记录。许可证和贡献来源单独保留。
