# FreeTerraForged 预测初始化修复

用户整合包安装的实际文件为 `ftf-unstable-1.0.0023+mc1.21.1-neoforge.jar`。
2026-11-02 22:59:56 的客户端日志显示：VSS 创建 Java 群系与装饰上下文时，
`copyClimateContext` 将空的出生点搜索状态传入 FTF 的非空 setter，触发
`NullPointerException: spawnSearch`，随后整个维度的预测初始化失败。
此故障发生在加载任务开始之前，不能按吞吐慢或 CPU 饱和解释。

修复按以下顺序传递状态：

1. 来源已有搜索状态时，原样复制，包括用户选择的位置。
2. 来源缺失而目标已有状态时，保留目标状态。
3. 两者都缺失时，恢复上游声明的 `WORLD_ORIGIN` / `BlockPos.ZERO` 默认状态。

群系生成策略、完整 64 位种子、预设、地表上下文和生成计划继续按原契约传递；
目标查询缓存仍独立拥有。旧版瓦片接口不经过新 helper。未改变真实区块生成开关，
未修改 Rust、地形精度、装饰数量或渲染路径。

## 验证范围

发行页的稳定版条目与滚动不稳定条目不同。滚动条目内的 0015–0023 是九个
不同构建附件，不能把同一条目的标签源码当成所有附件的实现。

- 11 个实际 NeoForge 发行 JAR：FTF 1.0.0、0015–0023、RTF 6005。
  每个独立 JVM 检查注册表往返、生成计划、过滤后的地形读取、水位、群系上下文和缓存释放。
- 0020、0021、0022、0023：执行真实 Sponge 气候 Mixin 转换后检查出生点契约，
  每版覆盖四种上下文状态。修复前该转换路径复现了与游戏日志一致的异常。
- NeoForge 1.21.1 和 Forge 1.20.1：公共气候采样、缓存与原生输入共享回归。
- NeoForge：原 Voxy 存储 Mixin 转换回归，检查测试工具初始化拆分后的行为。

以上逐构建检查合计 49 项，双端公共气候回归各 8 项，Voxy 存储回归 1 项；
正式验证入口额外重跑 0023 的 4 项测试，共 70 次测试执行，全部通过且无跳过。

逐构建测试结果与实际 JAR 校验值存放在本机
`external/performance/20261102-ftf-spawn-context/`。成品构建标识为
`20261102-cache-restore`，发布时核对源码快照和修复调用的实际字节码。

这些结果支持上述接口和采样路径的兼容结论。修复包尚需在用户的完整整合包重启后
确认预测初始化和最终画面，不代表所有预设、资源包、光影及模组组合都已验收。

Forge 1.20.1，不能据此声称其跨平台运行兼容。
