# 预测 LOD 水面交接与加载拉丝

日期：2026-10-05。适用于 NeoForge 1.21.1 与 Forge 1.20.1；承接 `prediction-occlusion-20261005.md` 的区域索引、深度回退与遮挡剔除。

## 复现与原因

截图中的海面边缘是大块浅蓝色带，三角形与台阶和粗网格相符。仅凭截图无法区分该处是否还缺少水面几何，但显卡回归确认了一个具体的水色错误：索引表示某列已归 Voxy，当前帧主深度在这个像素却是 clear；旧片元着色器仍裁掉混合瓦片的预测固体海底，而预测水面按既有规则保留。半透明预测水于是混合了天空，而不是海底，形成显眼的亮带。旧 GPU 用例在中心水面 RGB 的红通道得到 71，完整水+海底参考为 41。

加载拉丝是另一个明确的错误。旧顶点着色器用各顶点自己的坐标判断面的朝向，随后把判定不可见的顶点移至 `vec4(2,2,2,1)`。斜地形或加载 morph 会让一个面的角点分居相机眼高两侧，于是只有部分顶点被移走，剩余三角形被拉向右上角。旧 GPU 用例在原四边形投影范围外检测到 450 个绿色像素。

## 修改

- 顶点级整面剔除只用于法线轴坐标四角相同的面；可变高度的斜面和 morph 中的面保持原投影位置，在片元阶段按既有 flat 可见性标记处理。平面整面剔除仍可节约光栅工作。
- 索引硬裁固体时还要求当前帧存在真实深度像素。混合瓦片中索引覆盖却无实际像素的位置保留预测海底，供半透明水面混合。水仍通过既有的真实深度和同面容差处理，避免双层水；完整内区瓦片的 CPU 退休策略未变。
- GPU 回归加入斜面、原本平面但在 morph 中变斜的四边形，以及索引有覆盖但实际深度缺失时的水与海底合成。普通、Iris、索引绘制和实验 instanced 绘制都运行这些场景；既有区域交接回归检查真实像素存在时固体/岩浆/冰仍让位、真实水优先、索引撤销恢复。

## 验证边界

两端源码改动及平台适配见源项目 `build/water-streak-20261005/sync-manifest.json`。本轮产物、测试计数与哈希记录在同目录的 `verification.json`。显卡回归使用 RTX 4070 Ti SUPER 的隐藏 GL 上下文，覆盖合成场景；它证明指定着色器错误已消失，但不能代替用户整合包中原位置、相同视角和加载过程的现场验收。特别是已整瓦片退休的区域，如果 Voxy 自身缺像素，混合瓦片的片元回退无法补齐它，应结合现场截图再次区分实际缺水面与错误混色。
