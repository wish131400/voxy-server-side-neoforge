## 剩余较大部分：预测归属区段

第二次独立核验去重统计 6,419 个 payload，其中预测归属区段约 55,320,062 条。

| 元数据 | 数组浅大小 |
| --- | ---: |
| 归属区段 boxes，6 个 float/条 | 1,327,784,192 bytes，1.237 GiB |
| 归属区段 ends，1 个 int/条 | 221,370,088 bytes，211.11 MiB |
| 归属类型，当前安装包为 boolean[] | 55,419,672 bytes，52.85 MiB |
| 上述归属数组合计 | 1,604,573,952 bytes，1.494 GiB |
| 遮挡 meshlet 包围盒数组 | 11,033,192 bytes，10.52 MiB |
| ready 瓦片接缝摘要保留估算 | 500.31 MiB |
| ready 瓦片柱体区间保留估算 | 46.35 MiB |

归属数组比压缩后的网格正文还大。它们供 CPU 做 Voxy 接管/有效范围判断，目前没有进入几何压缩 blob。预测树叶、草、建筑的细小面使连续区段较碎；构造器只合并相邻且符合相同 X/Z footprint、类型等条件的区段。每条区段约 29 bytes 的载荷累加到数千万条，就会形成 GiB 级常驻数据。此处是预测网格自己的归属区段表，不等同于服务端/客户端真实列存在索引。

接缝、柱体和样本数字来自 ready 瓦片已有保留估算，不是全堆精确归因；跨瓦片共享对象可能重叠。ready 瓦片保留总估算也已经包含几何、归属、接缝和样本，不能把它再次与表中的子项相加。

## 保留范围与回收策略

当前配置为预测距离 4096 方块、细节距离 1536 方块、中等植被、高性能档，predictionCompressMeshes=true。

第二次统计 ready=6400，其中 desiredKeys 中有 1831 个，另有 4569 个当前不在 desiredKeys；两个集合的保留估算分别为 1.239 GiB 和 2.477 GiB，总计约 3.716 GiB。desiredKeys 是规划目标集合，不是本帧可见集合。不在其中的瓦片还可能承担祖先/交接/回退或范围内缓存，不能据此直接全部删除。

生产 PredictionMemoryBudget 使用 JVM 自由堆与工作区预约准入，当前安全余量为 1 GiB；这个安全余量不是 VSS 的 CPU 缓存配额。PredictionTileManager.pruneReady() 对部分冷缓存执行范围/落盘回收，另外的细节回收主要在内存压力出现时触发。视距内回退保护会继续保留数据，因此无损压缩减少每块体积以后，更多块仍可能驻留。

9.03 GiB 是已提交堆，6.10～7.42 GiB 是瞬时已用堆；已提交空间不会因为释放数组立即全部还给系统。本次没有全堆归因，也没有强制收集后完整 live set，不能把剩余差值全部称为原版/其他模组内存，更不能据此排除 VSS 的其他引用问题。和上份旧包报告位置、瓦片规模与活动状态不同，不能把旧 9.2 GiB 与本次数值直接相减作为修复收益。

## 下一步优化建议

1. 优先紧凑化归属区段元数据：用可验证的局部整数边界、重复 footprint 字典和共享包围盒减少重复数据，保留细坐标/高度边界及整棵预览交接语义。不能只删掉边界或降低证明精度来省内存。
2. 按热/冷状态管理元数据：热网格保持快速归属判断，冷网格减少大表驻留，在后台恢复/重建完成后再参与需要这些证明的提交。覆盖撤销恢复必须及时，不能在渲染线程逐帧解压。
3. 为可回收 CPU 缓存加入字节目标与高低水位；同时保留近景、可绘制祖先及交接保护，避免清缓存造成黑洞或反复生成。
4. 补充未压缩对象的有界延后重试，并单独计数并发跳过与收益不足。当前未压缩数组约 110 MiB，收益优先级低于约 1.49 GiB 的归属表。
