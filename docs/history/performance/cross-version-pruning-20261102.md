# 全版本装饰候选提前筛选

构建：`20261102-cross-version-pruning`，版本 0.3.7，日期 2026-11-02。

## 生产改动

将 26.3 的候选范围与精确群系证明接到全部八个 Fabric 目标，以及 NeoForge 1.21.1、Forge 1.20.1。提前证明候选范围内没有任何允许群系时，才跳过该 placed feature 的候选生成、环境扫描与地表查询。保留原 feature 索引、执行顺序及随机种子；不删除树、矿物、地下装饰或模组内容。

证明使用实际噪声依赖、原气候量化和群系参数。保留所有等距候选，并覆盖 BiomeManager 八个 quart 角及负坐标。不能证明的来源、未知或被修改的放置规则，以及缺少新接口的外部旧原生库均走原路径。支持已有规则组合的数据包与模组可通用获益；自定义 Java 回调不被强行简化。

旧版通过实际类型身份识别谓词，避免 Fabric 发布重映射后仅开发环境生效。高度、随机偏移与扫描 API 分代适配。证明缓存按世界维护，最多 4,096 列及 2 MiB 数值载荷；该载荷上限不等于包含容器和工作区在内的总进程内存。

生产放置另用轻量状态入口，避免构造未消费的诊断 JSON。原诊断接口与外部旧 ABI 6 缺符号回退保留，不对这项整理单独宣称稳定提速。工作区 scope、纯噪声 memo、规则线性化和标量群系入口经完整路径复测后无稳定收益，未加入生产。NeoForge/Forge 继续使用原 Java 精确群系缓存路径。

## 验证与边界

Java/JNI 专项共 677 项通过，零失败、零错误、零跳过。Rust release 回归：neoforge: 179 通过、4 项明确忽略；fabric: 260 通过、4 项明确忽略。

测试涵盖候选包围范围与真实放置输出、provider/谓词回退、六方向扫描、负坐标与边界溢出、真实 JNI 群系集合与 palette 重排、Y 依赖气候拒绝证明、取消，以及轻量放置入口与诊断入口的方块、编辑日志、随机流及失败语义。共用放置夹具明确要求实际写入和非空日志；Fabric 26.3 另用旧原生库执行缺符号回退，1 项通过。

两套原生核心分别重建 Windows x86-64、Linux x86-64/aarch64、macOS x86-64/aarch64，成品检查核对 JNI 导出、架构、源码与原生库摘要、Linux GLIBC 和 macOS 部署/签名。NeoForge 与 Forge 只在原生源码和五库摘要相同后共享构建产物。所有十个 JAR 检查实际字节码调用链、构建标识及打包源码快照。

此表未包含磁盘读取、客户端调度、渲染、帧时间与连续移动。没有本轮整合包实机画面、FPS、Linux/macOS 或 ARM 执行结论；不能将生成耗时降低直接等同于 FPS 提升。模组未知回调保留原路径，未声称覆盖所有模组与所有群系配置。
