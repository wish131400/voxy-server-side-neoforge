# 装饰高度查询优化与候选筛选对照（2026-10-31）

构建 `20261031-decoration-height`，VSS 0.3.7，覆盖 NeoForge 1.21.1 与 Forge 1.20.1。

## 最终实现

- 未被修改的 Rust 地表柱直接使用已保留的十字段记录回答高度查询。根据空气、冰/流体、表层、下层及深层的连续材料段判断，仍使用原有 `proxyBlock` 的完整 BlockState 与 Heightmap 谓词；不为只求高度的请求构建 ClientColumnSample，也不逐格扫描同一材料。
- 高度查询不再提前创建 6,400 项列版本数组，第一次实际写入时才创建。逐柱版本零专用于没有写入的列；放置、磁盘恢复和回滚都登记写入。版本回绕跳过零并失效缓存，避免把已有覆盖方块误判为原始地形。
- 有写入的柱、体积地形和 Java 兼容采样器沿用逐块查询。精确/显示视图分别读取自己的原始记录，切换视图继续失效高度缓存，关闭、取消和线程中断在缓存命中前检查。
- 保留原有缓存证明式群系筛选。没有将来源中心群系当作跨边界特性的完整判断，也没有调整随机调用、全局 Feature 索引或放置顺序。

## 未采用的候选

先在隔离副本比较材料段高度、纯 BlockPredicateFilter 后紧邻 BiomeFilter 时主动查询群系，以及两项组合。只对已审核、未被改写的原版纯谓词测试前置群系拒绝，EnvironmentScan 仍要求缓存证明。每方案两片预热、三片正式区域，使用前后两个已预热控制按相同区域配对，30 片完整输出摘要一致。正数为减少，负数为增加。

| 候选 | 完整生成耗时减少 | Java 分配减少 |
| --- | ---: | ---: |
| 初版材料段高度 | 0.53% | 2.11% |
| 纯环境谓词前主动查询群系 | -0.44% | 0.00% |
| 两项组合 | 1.00% | 2.10% |

主动群系筛选虽然增加拒绝数，精确地表采样点和批次数没有下降，整体耗时没有稳定收益，因此没有加入生产实现。原始数据为 `build/decoration-plan-20261031/`。组合单次略快不能证明主动群系筛选有效。

## 最终完整生成对照

实际 NeoForge 运行时、原版主世界、种子 42，每片 16×16 目标区块，装饰额外一圈来源。四组依次为初始基线、已预热基线、最终方案、尾部基线；每组两片预热、五片正式区域。统计最终方案与前后已预热控制的同区域均值，初始基线只用于建立结果摘要与预热。所有组都固定外部 shuffle 熵，不消耗 Feature 的随机流。

最终方案包含生产代码的材料段高度、懒分配与逐柱写入判断；隔离副本只注入版本选择和计数。28 片输出的装饰坐标及完整 BlockState、最终地形列/群系、排序包围盒摘要全部一致。时间不包括上下文创建、摘要计算与渲染。

精确地形请求量没有显著减少，装饰仍是主要成本。这轮解决了高度查询中的重复工作，并未完成覆盖任意模组的整来源群系范围证明，亦未新增 Rust 轻量元数据接口或替换 Java 群系语义。后续大幅收益需要让确定无效的装饰真正避免触发精确地形，而不是只增加前置检查。

## 验证与交付

- 新增 7,776 组材料/高度/流体/标记组合，对全部六类 Heightmap 进行 46,656 次逐块对照；覆盖树叶、透明方块、草本、空气、流体、冰、无地表标记、低于下限及高于上限。
- 行为回归覆盖负坐标、精确/显示切换、写入前尚未查询高度、磁盘恢复、树叶顶点、移除方块、失败回滚、版本回绕、下界体积以及热缓存取消/关闭/中断。
- NeoForge 共 462 项、Forge 共 463 项 Java 模块及原生接口回归通过，无失败、错误或跳过。首次测试发现测试夹具没有声明叶子等材料，以及 Forge 草方块名称与 1.21 夹具不一致；补齐夹具并改用双端共有的蕨后，完整相关专项重新通过。生产代码不依赖该名称替换。
- Rust 源码和五平台原生库与 `20261031-density-reuse` 完全一致，没有在本轮重复执行 Rust 全套测试或交叉编译；两端 Windows JNI 路径已在本轮回归运行。其他平台仅沿用上轮交叉构建与静态审核证据。
- 发布前校对两主项目与测试源码快照，检查两个 JAR 的构建身份、关键方法、字节码版本、全部原生库摘要及 ZIP 内外一致性，备份后更新两个根 `lib`。
