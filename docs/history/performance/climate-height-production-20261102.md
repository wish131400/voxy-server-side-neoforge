# 气候与精确高度优化生产实施（2026-11-02）

本轮将另一个对话已验证的水平气候输入复用、干燥空气证明和含水层候选邻域复用接入全部维护目标。版本保持 0.3.7；目标为 NeoForge 1.21.1、Forge 1.20.1，以及 Fabric 1.20.1、1.21.1、1.21.11、26.1、26.1.1、26.1.2、26.2、26.3。

## 实际改动

- 水平气候复用：只复用已证明不依赖 Y 的输入；跨 Java/Rust 复用需核对种子、表达式、实际噪声和精度身份。限定容量与生命周期，详情见同目录气候实施报告。
- 干燥空气证明：保留负密度区间、完整候选集合、原有等水位和所有必要回退。在所有候选底部均为空气且底部至少高于最高候选水位 5 格时，可严格证明当前压力计算不需要屏障噪声，且不会将空气变成实体，因而跳过逐格重复查询。
- 含水层候选复用：同一实际 X/Z 以及 `(y+1).div_euclid(12)` 范围内复用 12 个随机中心及水平距离。每个 Y 仍重新计算垂直距离、最近三点和流体压力；遍历顺序和 `>=` 平局规则保持。每个任务固定数组，换区块和挂起恢复重建，不增加共享锁。

这三项保留原输出，不引入树模板重散布、降低采样精度或删减装饰。前一轮 surface-demand/ore 小收益原型未混入本次生产变更。

## 生产入口的增量收益

测试在 Windows x86_64、NeoForge 1.21.1 的实际服务端运行环境中完成。三种模式均开启当前气候复用；只切换新增两项高度优化。每种模式两次预热、五个相同种子/坐标的正式区域，每个区域为 16×16 区块，包括地形、植被和预测数据编码。该夹具使用 Rust 地形与 Java 兼容装饰/群系查询，保持各模式路由一致；并不代表所有模组都走相同路径。计时不包含上下文构建、输出哈希、渲染、Voxy 网格发布、网络或磁盘落盘等待。

| 指标，中位数 | 首组基线 | 高度优化 | 尾组基线 |
|---|---:|---:|---:|
| 完整耗时 ms | 3618.732 | 3186.318 | 3501.767 |
| 装饰耗时 ms | 3377.740 | 2833.072 | 3270.657 |
| 当前线程 CPU ms | 3578.125 | 3156.250 | 3468.750 |

对较快的尾组基线，完整耗时减少 **9.01%**，等价吞吐约增加 **9.90%**；线程 CPU 减少约 **9.01%**。十五次正式生成及六次预热的完整输出哈希一致。首尾基线存在预热和系统波动，因此采用较保守的尾组基线，不将本结果与前阶段气候收益直接相加，也不将其表述为 FPS 提升。

气候阶段另有十目标专项验证和气候核微基准：旧精度目标核耗时减少约 60.9%–67.0%，26.3 减少约 11.7%；这些是气候核局部数据，各版本总体加载速度尚未逐版实机对比。

## 26.3 与回退

现代密度使用 FP32；当前中心选择和压力公式仍由公共 Job 路径以 f64 执行，故五格证书同样适用。现代流体 floodedness/exclusion/spread 水位计算保持原路。未扩大证明的 footprint，也未跨 volume 强行复用：完整列顺序、结构 beard、未知或非有限区间，以及插值格跨体积边界仍走原路径。未来如压力公式改变，必须重新证明该阈值。

## 正确性验证与限制

- 公共原生核心：四项干燥空气证明检查、两项最近候选及生命周期检查、四项十字段记录差分通过，覆盖多维度/种子、远坐标、重访、自定义规则/命名空间、寒冷/特殊地表和暴露状态节点回退。
- Fabric 原生核心：上述检查通过，另有现代压力阈值及单列/区块体积、换列/区块、挂起恢复、浮空薄层、抬高水面、排除配置逐格 oracle 两项，以及不同插值网格地表对照一项通过。
- 既有十目标 Java 气候专项共 82 项通过；实际 JNI 身份、取消/退出、预算、六根原始浮点位与 26.3 体积语义均有检查。
- 性能仅在本机 Windows x86_64 单线程实际入口测量；Linux/macOS 与 ARM 包经过交叉编译及导出审查，没有相应硬件实测。没有测量本轮游戏 FPS 或完整 Voxy 显示完成时间。
