# 26.3 装饰候选排除与完整路径验证（2026-11-02）

本轮将群系可能范围的证明接入 Fabric 26.3 的生产装饰入口：在生成候选、查询高度和材质之前，排除整个候选范围都不可能通过群系过滤的装饰。保留原有方块结果、Feature 随机种子和全局执行索引；未知实现继续原路径。

## 为什么不显示地下仍有地下计算

预测不构造完整真实区块，但 Java 装饰仍可能在随机高度检查地下材质、向上扫描空气、查询洞穴群系，然后在输出整理阶段剔除不连通地表的方块。树根、泉水及部分地表装饰也会读取下方环境，因此不能仅凭“地下不显示”关闭所有地下查询。

本轮提前排除的是确定不可能通过群系过滤的工作，不是统一禁用地下装饰。能通过过滤的装饰与仍无法证明的自定义路径继续执行，地下查询尚未全部消除。

## 实现与边界

- Rust 将 MultiNoise 参数树按相同深度区间分组。在相同区间内，严格更差的水平距离不可能成为任意高度的最终结果；保留全部等距候选，再用深度距离包络做保守排除。证明不调用实际群系搜索，也不改变其 last-result 状态。
- 温度、湿度、大陆、侵蚀和奇异度须由依赖图证明与高度无关。深度使用可证明的全局范围，必要时按 Raw 语义求固定 X/Z 的区间；Raw、Single、Cell 和现代浮点体积语义保持分离。
- Java 审计首个 BiomeFilter 之前的放置器、整数与高度 provider、嵌套谓词及已修改类，计算保守候选包围范围，并覆盖 BiomeManager 所有八个 quart 角点。后续放置器不参与此前的范围证明。
- 仅支持已审计、无自定义副作用的实现；无法证明的自定义实现、未知源、Y 相关水平气候、过大的候选范围和坐标预算以外区域保留原路径。Fixed 与普通 MultiNoise 可进入；TerraBlender、Blueprint 等位置路由没有直接套用普通 MultiNoise 证明。
- 正确处理硫磺池的向上扫描、海草的梯形偏移和负坐标。条件中的 Holder 集合无需为范围分析重复序列化，避免注册表上下文缺失导致整个分析器退回原路径。
- 每个世界的列证明缓存最多 4096 项、数值 payload 最多 2 MiB，此外仍有 Map/Arc、分组树和求值工作区开销。每线程 JNI 输出按实际群系调色板分配，原版 67 项为 268 字节，未固定分配 256 KiB。

本轮 Java 入口仅在 26.3 启用。其他 Fabric 目标共用重新构建的原生库，但不据此宣称获得相同装饰提速；NeoForge / Forge 保留原已验证生产核心。

## 完整路径对照

测试使用对应版本真实服务端资源、标签、注册表与生产入口，种子 42，单生成线程，16×16 目标区块，含边界的 324 个源区块，地形间距 4、装饰间距 1。每次包含 2 片预热与 5 片正式、互不重叠区域。流程为地形、按序装饰、地表整理、Voxy 输入编码；没有包含磁盘读取、客户端调度、网络或 Voxy 网格绘制。

对照只在冻结副本中关闭新筛选，两边使用同一原生库。为核对输出，隔离工具按世界种子和坐标固定原生 stage 的外部 shuffle entropy，没有修改 Feature 的 RNG。

七片区域的最终输出 SHA-256 在候选、同库对照、最终库及上一批已交付 26.3 构建之间全部一致。最终七片实际执行 224532 次合格筛选检查，172592 次被排除，发起 6804 次矩形证明查询；被排除的调用比例不能当成整体加速比例。

## 为什么局部排除很多，整体仍只有有限收益

单独的归因运行确认了真实进入路径：硫磺池调用中位数从每片 324 次变为 0，硫磺泉从 324 次变为 0，海草合计从 2592 次降到 213 次，洞穴藤蔓从 324 次降到 255 次；两边七片输出仍全部一致。

然而，原本由这些装饰首先触发的冷地表查询，很多仍被后续沙盘、发光地衣、竹子等装饰需要。冷计算成本转移到后续消费者，不能把各 Feature 减少的耗时直接累加成整体收益。归因运行整片精确地表点数中位数仅从 89984 降到 86864，约少 3.5%；对应地表调用时间约从 1985 降到 1841 ms。群系调用从 138272 降到 87367，约少 36.8%。

这些是带探针的独立归因数据，包含探针成本，不与无探针的完整耗时混算。它表明下一步需要降低保留列本身的地表/材质/环境求值成本，或减少接口与工作区周转；继续只消除不会写入的 Feature，不能按其局部计时推断成倍提速。

## 回归与交付

- Rust release 全量回归 260 项通过，4 项显式跳过的离线探针；包括真实现代群系源、随机模组参数与等距候选、深度包络的整数穷举、浮点与双精度 Raw 范围、原有地形/材质/植被随机续流回归。
- Java 与 JNI 定向回归 71 项通过，其中新增筛选检查 9 项；覆盖真实硫磺池、海草、洞穴藤蔓资源、首个群系过滤范围、修改类回退、负坐标、调色板重排、Y 相关气候、短输出缓冲和取消任务。
- 五平台原生库从最终源码重新构建。交付审计核对架构、全部 52 个 JNI 导出、GLIBC 2.28 上限、macOS 11 部署基线和 ARM macOS 临时签名页哈希；Linux/macOS 及 ARM 硬件没有实际运行。
- 构建标识为 `20261102-decoration-pruning`，标准 JAR 与 ZIP 不追加自定义后缀。Fabric 八目标分别构建核验；配套 NeoForge 1.21.1 / Forge 1.20.1 合包重新核对已验证 JAR 与主仓库源码，新增的是本轮报告。

本轮没有新的实际游玩 FPS、连续移动、传送、二次进入和画面验收。26.3 装饰仍占完整时间约 94%，最终完整生成仍慢于此前约 3.08 秒的 NeoForge 1.21.1 参考；这次提前排除减少了一部分无效工作，没有完成版本间性能追平。
