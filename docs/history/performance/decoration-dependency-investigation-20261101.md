# 装饰精确环境依赖复用实验（2026-11-01）

本轮寻找能超过逐项小修收益的结构性方向。只新增隔离实验工具和证据，没有修改生产 Java/Rust、正式原生库或 lib 交付包。

## 结果与取舍

最有价值的原型是跨工作区复用已证明可复用的插值角点，再组合紧凑算术求值。完整区域耗时从本组重复控制平均 4,286.78 ms 降到 3,659.42 ms，按同坐标区域配对的平均耗时下降 14.60%；装饰下降 15.01%，生成线程 CPU 下降 14.75%。这相当于本场景生成吞吐约 1.17 倍，不是翻倍，也不是游戏 FPS 结果。

独立扩大普通噪声、纯子图或所有环境根结果的复用，整体收益只有约 3%–5%。不建议把这些原型全部堆入生产。相同查询模式下，复用位置和进入路径的成本比单纯加大缓存更重要。

这轮仍没有达到上一轮讨论的 20%–30% 架构收益目标门槛。找到了比之前约 5% 更值得保留的原型，但没有找到保持既有输出、整体两三倍的实现。

## 新的归因证据

之前的 `prof::noise_evals` 只统计部分节点，未覆盖 `Shift`、`Shifted`、`Weird` 内的普通噪声调用。本轮在实际 `Graph::noise` 入口记录输入，并在 `Graph::compute` 统计节点分派、水平缓存和 memo 命中。探针只注入独立副本，不使用该构建的耗时计算收益。

输入按确定性哈希抽取 1/64，键包含普通噪声编号及三个 FP64 坐标的完整位值。一次正式区域内最多保存 100 万个抽样键，两片正式区域都没有丢弃记录。它统计同一区域的重复，不代表这些重复在有界缓存中都能命中，也不是跨所有世界的精确重复率。

| 正式区域 | 普通噪声实际调用 | 抽样调用 | 抽样唯一输入 | 抽样重复比例 |
| --- | ---: | ---: | ---: | ---: |
| 0 | 4,336,983 | 68,162 | 21,828 | 67.98% |
| 1 | 5,369,196 | 85,502 | 23,328 | 72.72% |

区域 0 约有 5,447 万次实际节点分派，其中二元运算约 1,905 万、Marker 约 1,204 万、常量约 922 万。区域 1 实际分派约 6,506 万。地表提交的约 8.6 万个坐标不同，并不能排除底层纯数值、插值角点和子图在不同工作区重算。

## 实验方式

Windows x86_64，NeoForge 1.21.1 实际运行时，原版主世界种子 42；每片 16×16 目标区块，装饰来源含外圈共 18×18；显示间距 4。每模式两片预热、五片正式新区域。各组独立执行，无并发编译/测试，没有渲染；固定独立 shuffle 熵，保留原 Feature 索引、主随机流、结构/Java/原生特性顺序和事务。

各组顺序均有初次 baseline、预热后的 baseline_repeat、候选和末尾 baseline_tail。以下百分比按相同区域相对两个重复控制的均值配对，再取平均。不能跨组直接比较绝对毫秒。各组重复控制的逐区域波动约 0.16%–2.95%，远小于最佳原型约 15% 的改善，但不保证别的硬件或整合包相同。

| 组别与候选 | 额外复用槽 | 整体耗时下降 | 取舍 |
| --- | ---: | ---: | --- |
| 普通噪声与 Blended 叶结果 | 8,192 / 32,768 / 131,072 | 3.30% / 3.53% / 3.15% | 不是主要方向 |
| 完整纯子图边界 | 32,768 / 131,072 | 3.76% / 3.25% | 不是主要方向 |
| 受支持插值角点 | 32,768 | 11.67% | 值得保留 |
| 角点加 Flat 初始化入口 | 32,768 / 131,072 | 11.25% / 13.02% | 本图未走 Flat 初始化入口，主要是角点和容量收益 |
| 角点加环境根结果 | 32,768 / 131,072 | 4.95% / 3.93% | 相比只复用角点回退，排除 |
| 紧凑算术计划 | 无额外结果缓存 | 2.58% | 单独收益小 |
| 紧凑算术计划加角点 | 131,072 | **14.60%** | 当前最佳实验原型 |

角点复用在现有 `Single` 插值角点入口生效，复用整段依赖的数值。原型只允许既有 covered-flat 范围证明内的坐标，排除暴露顺序状态和 Beard 依赖，保留外侧和无法证明情况的原计算。没有移动 BiomeFilter、跳过 Feature、改变 FP64 精度、减少请求点或降低装饰数量。

紧凑计划只处理常量、梯度、Unary、Binary、Clamp 和 Range 等算术区域；Marker、噪声和其他节点继续委托原实现，保留分支短路及浮点顺序。它是较小的解释器结构实验，不是机器码 JIT，也不是完整 Tungsten 编译器。

## 输出、CPU 和内存

五组共 189 片运行（含控制与预热），装饰完整坐标/方块状态、地形列/群系与最终包围盒摘要均与各自 baseline 一致，全部完成标记为 success。最佳组合所在组 35 片，全部一致。每片新区域，包含相邻来源区块之间的复用；不能据此宣称从不受益于邻域热数据，亦不是重访已完成装饰缓存的速度。

最佳组合的正式五片均值：

| 指标 | 重复控制均值 | 最佳组合 | 配对耗时下降 |
| --- | ---: | ---: | ---: |
| 总耗时 | 4,286.78 ms | 3,659.42 ms | 14.60% |
| 装饰耗时 | 4,001.11 ms | 3,397.01 ms | 15.01% |
| 生成线程 CPU | 4,271.88 ms | 3,640.63 ms | 14.75% |
| Java 精确提交点 | 85,916.8 | 85,916.8 | 0% |

所有百分比按区域配对后取平均，不直接从表中均值相除。Java 分配基本不变。结果复用槽为实验线程局部有界表，每槽 48 字节：32,768 槽约 1.5 MiB，131,072 槽约 6 MiB。没有锁住世界共享表。这个容量尚未接入正式工作区预算，线程存活期间也不会因退出世界主动释放；它是明确的生产化缺口，不能直接把实验 DLL 放进交付包。

额外三项 Rust release 差分检查通过：

1. 主世界/下界/末地/放大地形、两个种子，精确和显示混合访问、反序、重访和远坐标迁移。累计 30,720 组十字段列记录完全一致。
2. 暴露垂直 Cache2d、Flat 遮蔽状态及修改密度图的原路径对照。
3. 四维度、两个种子、Raw/Single/Block/Cell 四模式、各 256 坐标，全部路由根值逐位一致。

尚未验证任意模组自定义图、实际并行多任务的整体吞吐/内存、Forge 运行时或游戏帧时间，因此这是研究结论，不是已交付兼容优化。

## 后续具体边界

若继续实现，应优先把可复用角点的身份、覆盖区域和字节预算整理成上下文级能力，复用现有图和工作区；不能让每次节点读取都执行完整能力分析。紧凑算术计划可以作为同一原型的补充，保留所有未知和状态节点的原委托。

先验证 32,768 与 131,072 槽在实际并行任务中的收益和总预算，控制退出世界后的保留。再检查减少角点工作区重复、稳定数据布局或更完整的算术编译是否继续有效；不要把本轮被排除的三个小收益表叠加上线。

本轮没有继续推进候选裁剪：先前理想化跳过对照的输出差异仍未定位，缺少安全性依据，不能用它补足收益目标。

## 复现与生产隔离

实验准备脚本位于 `tools/performance/decoration-hotspots/prepare_dependencies.py`、`prepare_noise_reuse.py`、`prepare_subtree_reuse.py`、`prepare_lattice_reuse.py`、`prepare_environment_reuse.py` 和 `prepare_arithmetic_plan.py`。所有输出需使用新目录。准备后在副本 native 目录编译 release 库，再复制到同一副本的 main-resources，使用既有 `experiment.gradle` 运行；不要替换生产资源。每个后续准备脚本串接前置原型，完整补丁只在副本内生效。

各候选正式命令、输入/源码清单和日志保存于 `build/decoration-*-20261101*`，最佳为 `build/decoration-arithmetic-plan-20261101-b`。中途两个算术准备目录因补丁闭括号错误未完成，只是准备/编译失败，不计入性能与正确性结果。

长期数据为 `tools/performance/decoration-hotspots/prototypes/dependency-results-20261101.json`，包含逐片行、配对控制、计数、实验 DLL SHA256 和正式源码未变核对。`summarize_dependencies.py` 可重建该记录。

最终对照核对 472 个生产 Java 文件、18 个生产资源及 158 个 Rust/Cargo 输入，全与本轮起始快照相同。没有覆盖其他对话的既有修改，也没有更新根 lib 或发布实验性能包。
