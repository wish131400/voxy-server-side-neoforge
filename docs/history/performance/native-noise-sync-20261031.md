# Rust 噪声优化同步（2026-10-31）

[性能历史目录](README.md)

构建标识 `20261031-native-sync`，版本仍为 0.3.7。本次把 Fabric 审查中测出收益、且适用于旧版核心的优化同步到 NeoForge 1.21.1 与 Forge 1.20.1。

## 改动

- NormalNoise、旧 BlendedNoise 和二维 Simplex 在检测到 SSE4.1 后进入专用函数，把 octave 循环、取整和噪声核一起内联，减少通用 Windows x86_64 路径的外部 floor 调用。
- 不支持 SSE4.1 的 x86 CPU 保留通用实现。未启用 FMA、fast-math 或降低坐标精度，不更换随机序列与浮点累加顺序；这是标量指令优化，没有新增多列 SIMD。
- 两仓库全部 39 个 Rust 编译输入（源码、Cargo 配置、锁文件）一致，因此构建同一套五平台原生库，分别安装并记录 SHA256。
- Fabric 26.3 的 FP32 角点数组、体积范围修复只进入对应现代密度路径。旧版插值语义不同，未用 Fabric 的整个核心覆盖旧版实现。

## 最终 Windows 原生库对照

Ryzen 7 7700、Windows x86_64、JDK 25。使用各游戏版本的实际世界生成快照、固定群系和共用方块属性，16 个相隔 4,096 格的窗口，共 1,024 列，七轮取中位数。下表为窗口内查询间距 4，单位毫秒。

旧版核心两个版本、三个维度、四种间距共 24 组完整十字段输出校验一致。下界间距 1 个别组几乎没有变化，不能把主世界的比例推广到所有查询。测量包含 CPU/JNI 地形显示计算，排除 Java 植被、磁盘、调度、Voxy 发布和渲染；不代表相同比例的 FPS 或整个加载速度提升。

- 通用／SSE 两条编译路径直接逐位比较，覆盖不同种子、坐标周期边界、Simplex 和带 smear 的旧混合噪声；2 项检查通过。
