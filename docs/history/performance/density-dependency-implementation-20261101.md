# 插值依赖复用与紧凑算术计划（2026-11-01）

构建 `20261101-density-dependencies`，VSS 0.3.7，NeoForge 1.21.1 与 Forge 1.20.1。

## 正式实现

插值输入按节点与完整整数坐标复用，结果保留 FP64。图先分析暴露的状态缓存和 Beard 依赖；只共享 Single 模式、对齐且被 FlatCache 覆盖的工作区内的插值输入。结构 Beard、暴露的纵向 Cache2d、不能证明覆盖的坐标变换等保留原路径。键冲突替换整个条目，不用近似键回答查询。

共享表改为图（世界）拥有的租借池，单表 131072 项、4 MiB；每世界最多四表、16 MiB，进程内表载荷总预算 64 MiB，按需分配。查询独占表，逐节点访问不加锁；只在取得、归还时锁池。额度不足或分配失败时正常计算，不减少任务或采样。停车、重定位归还表；取消世界立即释放空闲表，正在使用的表在请求结束时释放。图增加路由根时关闭旧池并重编译计划，跨世界不复用答案。池元数据和一次性算术计划另按图规模占用少量内存。

紧凑算术计划覆盖常量、梯度、一元/二元算术、钳位与范围分支。保留运算顺序、乘零和分支短路、Java min/max 及原有精度。Marker、噪声、样条和自定义节点委托原求值器；没有引入自定义树模板或重排装饰随机流。原生 Cache2d 的结果统一走函数收尾，防止特殊图的提前返回遗留“暂停嵌套复用”状态。

## 正式库独立对照

Windows x86_64，实际 NeoForge 1.21.1 运行时，原版主世界种子 42。每区域 16×16 个目标区块，含装饰边界共 324 个来源区块，显示间距 4。每组两轮预热、五个正式区域。

顺序运行上版正式 DLL、新版正式 DLL 两组、上版正式 DLL 尾部对照。Java 装饰流程一致，实验副本仅固定外部 shuffle 熵并添加归因记录。计时排除上下文准备与摘要计算，没有渲染；这段期间未并行构建/回归，已协调 Fabric 对话暂停重负载。前面的隔离开关试验及可能与其他回归重叠的计时不计入以下正式收益。

## 供其他版本同步

以下为本轮正式文件边界，需整组同步，不能只复制算术计划或 DLL：

- `tools/rust/vss-native-core/src/density.rs`
- `tools/rust/vss-native-core/src/terrain.rs`
- `tools/rust/vss-native-core/src/density/arithmetic_plan.rs`

`dependency_tests.rs` 为测试，另六项为生产文件。两端 Rust 文件逐一相同。生产化边界包括图拥有的租借池、16/64 MiB 表预算、取消清理、停车/重定位归还、重建根时失效和 Cache2d 统一收尾。未纳入全环境根、全纯子树和基础噪声的其他缓存原型。FP32/Vulkan 等其他版本专属路径需自行评估，不能据此覆盖其精度或后端。

正式源校验、双端验证、库校验与发布包清单保存于 `lib/builds/20261101-density-dependencies/`；新旧正式库对照位于 `build/dependency-core-20261101-old-release`、`-final`、`-old-tail`。隔离对照准备脚本为 `tools/performance/decoration-hotspots/prepare_dependency_comparison.py`，实验开关不进入正式库。
