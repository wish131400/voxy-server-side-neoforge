# 旧版密度范围与共享图计划同步（2026-10-31）

[性能历史目录](README.md) · [前轮通用噪声同步](native-noise-sync-20261031.md)

构建标识 `20261031-density-specialization`，版本保持 0.3.7。本轮审查 Fabric 前几轮优化在 Forge 1.20.1 与 NeoForge 1.21.1 中的适用性，两个旧版项目合入同样的改动，并共用同一组五平台原生库。

## 实现与取舍

- `density/column_plan.rs` 合并 `Node::Select` 的 fallback 和所有候选结果的范围。现有 Lithostitched 选择节点只返回一个分支；所有结果范围均有限时，包围它的插值器可继续复用对齐柱的两个有效角点。包含未知或非有限分支则沿用完整回退，不省去会影响结果的角点。
- `density/surface_plan.rs` 给符号优化计划增加 128 次总展开预算，避免共享子图被重复展开成巨大树。预算耗尽时保留原节点的精确求值，不拒绝原图，不限制实际计算量、生成任务或 LOD 质量；原有深度限制继续存在。
- 通用噪声内联与 SSE4.1 精确取整已经在前轮同步；单柱插值边复用、地表高度计划也已存在，不重复添加。
- Fabric 本次为旧／现代两种图分别编译的求值特化，在只有旧版 FP64 图的内核中没有相同收益来源，因此不加入第二套分支。26.3 FP32 AVX2、现代角点数组、现代符号包装与外岛有限范围不能直接覆盖旧版语义。
- 额外测过的常量提前返回没有稳定收益，未采用。旧末地的整数包装可能产生非有限值，保留其未知范围处理。

## 正式 Windows 库对照

Ryzen 7 7700、Windows x86_64、Rust 1.98.1 / LLVM 22.1.8、JDK 25。基线为前轮 `20261031-native-sync`；独立 JVM 串行运行，11 轮取中位数。固定群系与方块属性，16 窗口、1,024 列。正数为耗时下降，负数为增加。

原版三维度没有稳定的新增提速，主要在正常计时波动内。间距 4 的正式结果如下，不能据此把本次称为所有世界的通用性能提升：

| 输入 | 间距 | 基线 ms | 正式库 ms | 耗时下降 |
| --- | ---: | ---: | ---: | ---: |
| 1.20.1-overworld | 4 | 49.905 | 47.287 | 5.2% |
| 1.20.1-nether | 4 | 9.448 | 9.094 | 3.7% |
| 1.20.1-end | 4 | 16.721 | 16.296 | 2.5% |
| 1.21.1-overworld | 4 | 44.965 | 44.699 | 0.6% |
| 1.21.1-nether | 4 | 9.050 | 8.625 | 4.7% |
| 1.21.1-end | 4 | 15.515 | 15.472 | 0.3% |

在主世界参考图外包裹现有 Lithostitched Select 节点的受控输入，种子 -917：

| 输入 | 间距 | 基线 ms | 正式库 ms | 耗时下降 |
| --- | ---: | ---: | ---: | ---: |
| select-overworld | 1 | 8.208 | 8.355 | -1.8% |

隔离候选 19 轮反序确认中，间距 4 为 77.244 → 48.901 ms，16 为 172.487 → 60.681 ms，64 为 176.829 → 60.668 ms，方向一致。该输入用于验证有限分支丢失导致的重复角点工作，不能代表完整 Lithostitched 整合包、全部地形模组或 FPS。间距 1 不满足同样的角点裁剪条件，未见稳定收益。

计划预算主要解决特殊共享图的构造开销；新增检查用 36 层共享 Min DAG 确认计划规模有界，原图精确值和符号一致。没有给普通原版图宣称固定比例收益。

## 验证和交付

- 同一候选源码 72 项 Rust 检查通过，4 项原有外部／计时诊断保持忽略，涵盖库、15 项显示、3 项原版噪声和 10 项世界生成检查。
- 新增 3 项检查覆盖有限选择只读两个角点并逐位对照完整八角路径、离开对齐柱后的精确查询、非有限结果回退和共享 DAG 计划预算。
- 最终生产库在两个版本三维度与受控选择输入的 28 个间距配置中，完整十字段输出记录均匹配基线；冷查询与缓存查询均校验。生产 Rust 源码逐文件匹配已通过回归的候选，不用 Fabric 全目录覆盖旧版内核。
- Windows x86_64、Linux x86_64 / ARM64、macOS x86_64 / ARM64 产物交叉构建，两个主仓库 Rust 源码和五库 SHA 一致。最终原生包核对 42 个 JNI 导出、架构、glibc 2.28 上限、macOS 11.0 下限与 ARM macOS 签名。
- 交付保留标准名称，更新两个项目根 `lib` 的对应 JAR，并把相同 `vss-0.3.7.zip` 写入两处；源码快照、原生摘要、构建身份和校验值由发布工具核对。构建前的旧包有独立备份。
- 本轮只有 Windows x86_64 运行和计时；没有 ARM、Linux/macOS 运行、完整模组世界或游戏 FPS 测量。CPU/JNI 计算耗时不包括 Java 植被、磁盘、任务调度和 Voxy 发布渲染。
