# 地表规则兼容修复（2026-11-04）

构建标识：`20261104-terrain-surface-compat`，版本 0.3.7。

- 实现 BWG 的加权规则、循环噪声区间与地层条带，使这些已支持的规则可以进入 Rust 地形路径。保留随机源、坐标取整和规则顺序。
- 保留 BWG 的 shattered_glacier、eroded_borealis 额外侵蚀几何，不能将这些群系误当作只替换方块材质。
- 接入 Lithostitched 地表规则引用、规则标签与服务端注册表快照，保持成员顺序和空集合继续后续规则的行为。覆盖 RU 1.21.1 使用的这条路径。
- Incendium 的快速显示按当前列实际 Hole 条件判断。可能写入岩浆、空气或修改几何的列继续精确计算；自适应网格也检查未探测的内部列。
- 保留此前的加载调度、结构缓存共享、批量远景锚点和 CPU 入队公平性修复。

修复同步到 NeoForge 1.21.1、Forge 1.20.1 及 Fabric 共用核心和版本适配层。共用核心提供能力不等于所有模组都发行了这些 Minecraft 版本。

## 验证

- 两套 Rust 完整回归通过；最后补充的注册表传输和内部 Hole 回归也分别通过。
- 执行 BWG 2.6.3 发布包的实际算法，对两种随机源、三个种子、正负坐标及常量/均匀整数提供器，共 7,680 个采样结果逐项一致。
- 执行 Lithostitched 1.8.0 的实际 ReferenceRule 编码，以及项目服务端注册表依赖/标签导出，确认引用、成员顺序和空标签可到达原生文档。
- Incendium 5.3.5 / 5.4.4 的实际规则离线对照：26,624 条精确记录与旧核心一致；每套新核心的 13,312 个显示列中，精确回退从 13,312 降到 52。
- 该显示查询区段首次合计耗时从约 5,017 ms 降到 1,176 ms（旧版核心）及 1,062 ms（Fabric 核心）。这是共同 1.21.1 注册表夹具、逐群系固定输入的离线区段结果，不能当作整包加载或帧率倍数。
- 五平台原生库交叉编译，检查架构、JNI 导出、系统依赖和校验值。Windows 执行原生回归；Linux、macOS、ARM 未执行运行测试。

最终 JAR 经对应版本的 Java 回归、调用关系、构建标识、原生源码摘要与校验值核对。本轮尚未进行新的游戏画面及整合包实测。
