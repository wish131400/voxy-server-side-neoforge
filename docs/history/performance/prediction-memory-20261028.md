# 0.3.6 望远镜细化与预测内存优化

> 历史记录：保留当时的实现、输入与验证结果，不能据此判断当前版本的渲染架构、配置或兼容范围。 当前说明见 [文档目录](../../README.md)，相关旧报告见 [历史索引](../README.md)。

构建标识：prediction-memory-20261028。

- 修复细化队列满后丢失被推迟目标，导致望远镜放大或转向后远景迟迟没有新增细节的问题。等待目标保留轻量记录，视角变化时参与后台排序，完成任务后自动补位；待执行任务仍最多为 4096 个。
- 补齐被挤出任务晚完成、完成目标重新请求和冷数据恢复的状态衔接，保留需求身份，避免依赖再次遍历大量节点才恢复细化。
- 植被与建筑采用无损连续数据页和数组空间索引，保留坐标、方块状态及重叠顺序，并共享重复页面。
- 在原有 128 MiB 映射缓存总额内为整块、粗柱和邻面分配独立额度，减少互相挤占；邻面只分配实际覆盖区域的临时归属数组。
- 统一管理器和渲染数据源持有的最终数据引用，减少等价数据的重复保留。
- 长期离开视野且已有恢复条件的细化数据可解除常驻标记，保留轻量需求记录，回到视野后恢复；近处、当前显示及必要交接数据继续受保护。

保留现有 Rust / Java 地形与完整植被生成，继续统一使用 Voxy 构网、LOD、遮挡和绘制。磁盘体素缓存格式兼容，预测距离及生成精度保持现有配置。

NeoForge 1.21.1 与 Forge 1.20.1 均完成回归及发行构建，详细测试计数和校验值见 validation.json 与 manifest.json。

本次未替换正在运行的整合包模组。离线验证覆盖了加载、转向恢复、缓存和队列状态；安装后的实机加载延迟、内存占用及帧率仍需采样确认。
