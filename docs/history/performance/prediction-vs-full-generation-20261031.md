# 预测与真实区块生成对照（2026-10-31）

当前实现中，4 格间隔的纯地形预测相对从零生成 FULL 区块，累计进程 CPU 时间少约 49.3 倍，完成耗时短约 39.4 倍；包含植被、受支持地表结构和体素编码的预测，CPU 优势为 2.7～2.9 倍，完成耗时优势约 2.1 倍。

## 测量范围

- Ryzen 7 7700，Windows x86_64，Java 21.0.6，Minecraft 1.21.1 / NeoForge 21.1.234，VSS 0.3.7 当前生产源码与随包 Windows Rust 库。
- 原版主世界，种子 42，不安装 C2ME、其他世界生成模组、Voxy 或光影。测试 CPU 数据生产，不启动画面。
- 每轮同一片 16×16 个区块，即 256×256 方块。两轮预热后测五片新区域，总计 1,280 个目标区块。区域包含森林、丘陵、沼泽、丛林、雪地和海洋。
- 两阶段串行运行，真实生成在完整 NeoForge 专用服中使用 `ServerLevel.getChunk` 推进到 FULL；1,280 个目标全部通过 FULL 与光照正确性检查。每轮另有必需邻区依赖，新增 1,444 个区块持有者不等于生成 1,444 个 FULL 区块。
- 预测也在完整 NeoForge 运行时调用生产 `RustTerrainSampler`、`PredictionVegetation` 和 `PredictionVoxySource.build`。输入来自同一服务器的实际世界生成快照，结构模板也使用同一资源集；每种配置独立缓存，同配置各轮坐标不重叠，没有磁盘预测缓存命中。
- 1 格精度为 16 个 64×64 单元瓦片，4 格精度为 1 个同样单元数的瓦片。每瓦片含采样边界，并使用生产 8×8 原生批次。

## 结果

下表为五轮每区域平均时间；倍数按对应五轮累计时间相除。进程 CPU 时间累加线程的实际运行时间，包含 Java、Rust、生成工作线程、JIT 和 GC，所以可以大于实际等待时间。它是 CPU 开销代理，不是浮点指令计数。

| 路径 | 完成耗时/区域 | 进程 CPU 时间/区域 | 真实生成 ÷ 该路径 CPU | 完成速度优势 |
| --- | ---: | ---: | ---: | ---: |
| 真实区块 FULL | 10.847 s | 15.728 s | 1.0× | 1.0× |
| 纯地形预测，1 格间隔 | 0.851 s | 0.969 s | 16.2× | 12.8× |
| 纯地形预测，4 格间隔 | 0.275 s | 0.319 s | 49.3× | 39.4× |
| 地形＋植被＋受支持结构，1 格间隔 | 5.216 s | 5.869 s | 2.7× | 2.1× |
| 地形＋植被＋受支持结构，4 格间隔 | 5.223 s | 5.375 s | 2.9× | 2.1× |

4 格纯地形的逐区域 CPU 倍数为 33.0～64.0 倍，完成耗时倍数为 30.2～45.4 倍。加入植被和结构后，1 格/4 格两个配置的完成耗时几乎相同，说明只减少地形采样点无法消除完整地表生成和整理的主要成本；这些测量不能进一步拆成植被、结构、邻域查询各自的独占占比。

最终一组累计诊断记录到 79 个树模型构建、约 4,200 次模型放置及 88 次结构放置计数。完整路径输出了非空装饰体素，不是仅开启选项而跳过装饰。

## 结果边界

- 真实生成包含目标必需的邻区状态开销。连续生成更大区域能够摊薄边缘成本，因此不能把本表直接当成大规模预生成的固定倍率。
- 预测输出仅覆盖当前预测支持的内容，不等于可交互的完整区块。整个七轮（含预热）每个装饰配置还累计跳过 3 次装饰尝试和 11 次结构尝试；原因分别是写出有界区域、虚拟结构环境不支持 `getLevel`。没有发生缺少 NeoForge 流体注册表的失败。此限制会使预测承担的内容少于真实生成，不能宣称完全相同画面的成本对照。
- 没有计入启动、快照导出、Voxy 构网/渲染、网络、预测磁盘缓存读写和最终存盘；这些倍数不代表 FPS 提升倍数。
- 仅实测 NeoForge 1.21.1 原版主世界。不能推广成 Forge、Fabric、其他维度、模组地形或 C2ME 的实测结果。
- 早期普通 Java 离线预试验缺少完整 NeoForge 注册表，被排除在最终统计之外，留存在 `preliminary-headless`。

## 复现与证据

工具入口：`tools/performance/generation-comparison/run.ps1`，可指定 `-JavaHome` 和 `-Python`。它创建独立新世界，在本机回环地址运行两阶段测试，停止服务器后检查并汇总；已有输出目录会被拒绝，防止把缓存读取当成冷生成。

本轮原始文件保留于 `build/generation-comparison-20261031/`：

- `full-generation.csv`、`prediction.csv`：全部预热/正式轮次。
- `summary.json`：汇总与逐区域配对倍率。
- `server-launch.log`、`prediction-server-launch.log`：完整 NeoForge 启停与计时记录。
- `features-step*-round*.txt`：生成结果、树模型、缓存与失败诊断。
- `worldgen-profile.bin`、`structure-templates.json`：实际输入快照。
- `manifest.json`：CPU、原生库及关键生产源码 SHA256。

本轮新增的是测试工具与测量记录，不涉及生产生成算法修改。
