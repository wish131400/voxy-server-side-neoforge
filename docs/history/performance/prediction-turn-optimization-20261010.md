# 转向与移动热点优化实施记录（2026-10-10）

> 历史记录：保留当时的实现、输入与验证结果，不能据此判断当前版本的渲染架构、配置或兼容范围。 当前说明见 [文档目录](../../README.md)，相关旧报告见 [历史索引](../README.md)。

本轮按 `prediction-turn-profile-20261010.md` 中的实测热点实施，已同步 NeoForge 1.21.1 与 Forge 1.20.1。修改集中在候选对象分配、视野调度、静态间接提交验证、源快照发布和 Voxy 归属过滤缓存。

## 1. 转向候选与可见列表

- `PredictionRenderer.Scene` 复用广阶段瓦片集合与绘制候选集合，采用开放寻址集合，减少每次转向创建集合节点。
- 瓦片及两类接缝的 `DrawKey` 由场景缓存；瓦片和接缝完全退出后回收，清空场景时释放全部缓存。
- 只为实际存在的不透明绘制记录建立候选键；移除和加入仍在当前帧生效。
- `PredictionVisiblePlan` 只遍历当前可见成员清理过期候选，复用暂存列表，避免遍历整个驻留映射或重复创建暂存集合。
- `PredictionSpatialIndex` 直接创建带保守边距的包围盒，避免先构造再 inflate 的第二个对象。

当前帧的视锥判断仍执行；水面继续使用原有的透明排序。没有通过延迟可见性更新来减轻工作。

## 2. 视野细化调度

- 期望瓦片成员及层级数未变化时，复用父级与邻接依赖路径。转向只重新分类视野，不重新创建整套父子邻接键。
- GPU 反馈快照保留按维度、LOD 和整数坐标建立的索引。查询没有观测的祖先时，不再逐级创建 `PredictionTileKey`；实际命中则复用观测键，继续核对网格版本、归属 epoch、脏状态、时间和视角。
- 规划器在一次规划中缓存候选的视野与遮挡等级，避免优先队列每次比较都重新查询遮挡。
- 新的反馈快照仅在有效隐藏分类改变时触发轻量调度刷新；相同隐藏结果只更新反馈记录。提示过期、归属撤销、内容变化或转向仍能恢复优先级。
- 普通生成仅为尚未达到目标、没有在途任务、可以重试且没有被视野规则暂缓的目标构造排序请求。
- 成品缓存恢复独立遍历完整计划，不受普通生成目标过滤影响。排序只保存实际缓存候选的驻留状态，不再复制全部 ready 键。

可见远景仍按屏幕误差细化；隐藏区域降优先级；缺失覆盖、接缝依赖、脏内容恢复与望远镜路径保留原有例外。CPU 预约、执行时复核及释放规则保持有效。

## 3. 静态间接提交验证

- `PredictionPackedMesh` 发布提交元数据版本。
- `PredictionIndirectBatch.PlanItem` 先核对不可变绘制记录、范围、GPU 分配槽及少量可变元数据版本；命中后跳过完整签名生成、范围数组哈希和内容比较。
- 不同对象仍走完整检查；实际内容变化重建。等价记录或没有改变编码内容的元数据更新通过一次检查后，采用新身份和版本，下一帧继续走快速路径。
- 诊断增加 `planIdentityHits` 与 `planContentChecks`，后续可用计数增量确认实机复用程度。

这一步减少静态计划验证的 CPU 成本。候选成员、顺序、范围或 GPU 驻留变化时，仍需执行对应的准备和重建；当前帧 Hi-Z 继续更新。

## 4. 源快照增量发布

- 管理器维护不可变的分页瓦片表与 epoch 表。首次快照初始化完整表，之后只应用发布、删除及归属更新涉及的键。
- 网格与 epoch 在同一同步区间内交接；旧快照保持不可变。
- 复用 `PredictionTileTable` 的共享页与差异遍历，避免每次小更新复制全部 ready / epochs 并重新建立全部 LOD 索引。
- 没有实际网格变化时复用整个网格表；没有望远镜专属瓦片时跳过 scoped family 全表查找。
- 缩小视距、Voxy 归属变化与关闭清理也更新对应状态。

新增回归使用 2,048 个驻留瓦片：更换一个网格只替换一个网格页；仅 epoch 变化复用整个网格表；删除网格与新 epoch 一起发布；旧帧数据保持不变。

## 5. 覆盖过滤局部失效

- 不再因覆盖快照对象身份改变就清空所有网格条目。
- 相同窗口内比较真正用于 CPU 归属证明的 settled interior 列（255）。内容相同的新快照不增加归属版本；局部变化只撤销与变化列包围区域相交的静态证明。
- 未受影响条目复用静态证明、绘制范围和工作数组；受影响条目保留容量并立即重算。
- 相机或半径变化仍更新动态三维范围。窗口迁移、空快照与覆盖撤销采用保守失效；边界列继续交由当前帧深度判断。

多个分散变更目前合并为保守包围区域，可能额外失效区域内的网格；不会漏掉需要撤销的证明。覆盖撤销没有等待缓存超时。

重点验证包括：

- 转向、移动、候选缩窄再扩大后的恢复与距离顺序；空间广阶段不遗漏精确可见瓦片。
- 远处可见区域细化、背面暂缓、缺失覆盖与接缝依赖的保留；预约和取消不泄漏。
- 遮挡提示的过期、变向、内容与 epoch 失效、可见子瓦片覆盖旧父级提示。
- 等价覆盖快照复用、远处更新不重新过滤本地网格、局部撤销同次更新恢复几何、半径及窗口迁移。
- 真实 GPU 中稳定重放的完整签名比较增量为零；等价记录和元数据更新只核对一次；缓存和重新编码的 framebuffer 逐像素一致。
- 批次成员、顺序、截断、恢复、不透明与水面交替，当前帧遮挡、植被交接、两种深度约定及 GL 状态恢复。

条件跳过为：需要提供捕获网格目录的 spatial replay，以及需要指定实际 Voxy JAR 的 final-blit 深度测试。两种深度约定的独立交接与遮挡测试已运行，未把这些条件跳过算作通过。

本轮使用预测与渲染的独立测试源集。共享工作区中另一个改动方向的 `PredictionLodBackendsTest`、`PredictionFlatTerrainSamplerTest` 和 `TerrainCapabilityBenchmark` 不参与这次编译；本结果不是整个仓库所有服务端、世界生成适配测试的全量结果。
