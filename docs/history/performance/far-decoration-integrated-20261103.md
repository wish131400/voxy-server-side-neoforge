# 远区模板散布与固定粗网格实验接入

目标版本为 NeoForge 1.21.1 和 Fabric 26.3。实现走生产预测管理器、Rust 地形采样、剩余装饰生成与 Voxy 输入整理。实验改变远区装饰的位置和形态，不保证逐方块一致。

## 范围与开关

- `predictionFarDecorations`：默认 `false`。
- `predictionExactDistanceBlocks`：默认 `4096` 格。按整个地图片段的最近距离判断，另设 256 格提前升级区。
- 总预测范围仍由 `predictionDistanceBlocks` 决定。总范围默认也是 4096 格，因此默认没有可用实验外圈；试验外圈时可将总范围设为 8192 格，同时开启实验。
- 只接管 Rust 后端、非地下内部地形、采样间距不大于 16 格的外圈表面任务。更粗的第一层地形继续先显示地面；本实现不会为巨型地平线片段逐区块生成全部装饰。
- 精确区沿用现有装饰路径及其可见性调度，不强迫整个 4096 格圆面一次性完成全部精确装饰。
- Horizon 的其他版本保留能力判断为不可用，不自动启用未经审查的新版本 Feature 接口。

## 实现

从当前群系注册的可支持 Feature 中捕获三个实际模型，保持种子和世界坐标决定候选，使用固定 5 格候选网格。群系地表锚点仍在固定世界坐标采样；候选不随目标 LOD 移动。模板按目标体素分辨率直接合并，以去重后的实际占用量投票选择材质，旋转坐标时同步旋转方块状态。只包含树叶的粗体素需要至少 1/8 的细体素覆盖；树干与其他装饰保留。空白体积参与覆盖判定，同一位置重叠的树冠不能重复累加票数。

模型捕获会记录地表谓词及其实际布尔结果。不能将每次谓词查询都当成必须为真，否则树木对地面的排斥检查会令所有树被误拒绝。尚不能捕获的 Feature 保留原路径。结构查询继续使用原精度；其余实验环境使用显示地形，并把 Java 环境查询共享到固定 8×8 格网格。

模型由一个世界管理器拥有；每个并行任务有独立作用域和临时数据。远区回退装饰使用独立内存缓存，不读写精确装饰缓存。最终近似体素带运行时标记，管理器与磁盘写入口均拒绝将它存为精确完成记录。真实捕获列优先，世界编辑会失效相关回退结果。

靠近或传送后，旧远景保留到精确结果发布；旧的“表面已完成”状态不阻止升级。进入提前升级区会取消尚未完成的远区任务，发布入口再次校验距离和精度，防止迟到结果覆盖精确结果。几何相同的发布也必须更新精度状态。

树根只允许补齐到最高可见承托面，并限制为一个目标采样间距内；不能沿地下材质分层延伸。大坡度和粗体素高度差仍需要游戏画面检查。

## 对照测试

真实原版注册表，固定森林群系，种子 42；每片 16×16 区块，地形间距 4 格，1 轮预热、3 轮交替顺序测量。包括 Rust 地形、剩余 Java/native 装饰、模板散布和生产 Voxy CPU 输入整理；不包含磁盘、渲染上传、实际游戏整圈排队与帧率。

| 目标 | 现有路径总耗时中位数 | 实验总耗时中位数 | 完整路径加速 | 装饰与整理中位数 |
|---|---:|---:|---:|---:|
| NeoForge 1.21.1 | 2349.503 ms | 637.331 ms | 3.69× | 2146.412 → 440.715 ms |
| Fabric 26.3 | 2927.841 ms | 1106.133 ms | 2.65× | 2727.338 → 915.837 ms |

两版本不是在相同游戏运行时；表格表示各版本内部配对收益，不能据此宣称 NeoForge 天生比 Fabric 快。同机后台任务也会影响绝对耗时。

4096 区块、1024 格跨度、间距 16 的大任务另行完整执行，NeoForge 约 6.71 秒，26.3 约 15.67 秒。大任务仍可能持续较长时间；取消测试证明任务能响应失效，不代表游戏中每个近区任务都能即时获得线程。

木本体素占用对照有保留原始 Feature 的有效树木断言。加入覆盖权重前，正式三轮 NeoForge 比原路径多约 33%–46%，26.3 多约 36%–55%。加入覆盖权重后，NeoForge 为原路径的 97.03%、102.49%、97.24%，26.3 为 105.07%、121.86%、118.25%。这是目标粗体素下的占用量，不是树的数量，也不是位置或状态一致率。之前与之后的速度来自相同方法的不同运行，不能用两次绝对时间之差精确衡量权重计算成本。此前出现过树木被筛掉的无效测速，已由断言检出并废弃。

## 覆盖权重与画质边界

本轮只改变模板的粗体素覆盖与材质归并，不修改群系的散布数量或树种选择概率。模型与候选由种子、世界坐标及规则盐决定，覆盖判定不依赖视角、帧率或时间。共享模型初始化完成后清除首个任务的取消回调，避免保留该任务引用。

另一组种子 918273、128×128 格区域的完整生产路径用于检查不同群系。下表是 spacing 4 的最终木本占用比例；基准为各版本自己的现有预测装饰路径，并不是真实存档逐块标准。

| 群系 | NeoForge 相对占用 | Fabric 26.3 相对占用 |
|---|---:|---:|
| 森林 | 90.48% | 111.01% |
| 针叶林 | 73.59% | 65.22% |
| 黑森林 | 111.08% | 99.82% |
| 白桦林 | 96.10% | 83.64% |
| 丛林 | 100.19% | 77.52% |
| 平原 | 基准 12、实验 24 个粗体素 | 基准 0、实验 21 个粗体素，无相对比例 |

因此不能把森林的接近 100% 占用解释为所有群系画质达标。针叶林仍偏稀；平原样本只有少量树，位置变化使比例波动明显。没有为了匹配单一样本而硬编码群系倍率。4、8、16 格 LOD 的木本候选身份一致，各测试区域仍有树冠；覆盖归并不会产生模板原本未触及的新木本体素。这些检查不等于每棵孤立树的树冠、轮廓或颜色均已通过视觉验收。

模板仍不复现原装饰随机链，粗环境仍可能改变坡地、群系边界和未知模组 Feature 的表现。当前没有实际游戏画面、FPS 或模组环境验证；保持默认关闭。

## 验证与复现

新回归验证距离边界、负坐标、传送、管理器实际派发远区工作、靠近后精确升级、相同几何的精度升级、迟到结果拒绝、磁盘拒写、并发与异常后的作用域恢复、重复生成、木本锚点跨 LOD 稳定和真实捕获优先。离线测试不创建图形上下文。

设置环境变量 `VSS_FAR_BENCH=true` 可开启配对全路径测试；设置 `VSS_FAR_LARGE=true` 可开启大跨度任务和取消测试；设置 `VSS_FAR_QUALITY=true` 可开启六群系及跨 LOD 覆盖检查。两个目标均执行 `test --tests '*PredictionFarDecorationTest' --tests '*PredictionFarDecorationNativeTest'`；Horizon 另传 `-PmcTarget=26.3`。常规回归默认跳过这些耗时的测量方法。

使用 `tools/performance/far-decoration/summarize_integrated.py` 读取对应 JUnit XML，输出中位数、占用量和大任务记录。原始运行记录保存在忽略的 build 目录，不进入仓库。

NeoForge 离线夹具补足了正常加载器在注册阶段填充的方块状态 ID，确保粗材质投票确实产生树木，而不会把缺失 ID 变为空气。26.3 的越界写测试对齐已有的现代 WorldGenRegion 行为：越界返回 false，写入预算超限仍回滚并抛出本地失败。

## 最终回归记录

NeoForge 的架构、区块策略、模块、调度消费者、性能统计与地形交接检查通过。完整末地检查暴露了旧的 `affected` 辅助枚举遗漏当前缓存设置版本的问题；同步当前版本键后，末地检查与磁盘缓存、批量失效检查通过。生产失效路径原本按列记录失效，不依赖该辅助枚举。

Fabric 26.3 的模块与迁移检查通过；真实 Voxy/Iris 字节码契约检查发现两个旧接收回执夹具未模拟已经要求的实际提交回调。更新夹具以调用实际提交入口，并补充“worker 返回但没有提交必须失败”的检查，保持生产确认条件。修正后的回执检查与实际区段交接检查通过。外圈策略与真实 Rust/Feature 管理器测试已加入默认模块回归，耗时基准仍需显式开启。

以上为离线检查结果，没有用它替代实际游戏视觉和渲染帧时间验收。本轮没有生成或发布新 JAR。
