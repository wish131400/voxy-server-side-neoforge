**转向与客户端主线程优化实施记录（2026-10-14，0.3.5）**

本轮将主线程审查与《VSS 转向开销与 Voxy、Distant Horizons 源码对照》一起实施，已同步 Forge 1.20.1、NeoForge 1.21.1。基于当前工作树构建，保留既有功能及平台差异。本轮没有采集当前游戏的 JFR、连续帧或 FPS，没有启动客户端、替换整合包或推送 GitHub。

**提交组织与近期缓存**

- 不透明分组从“可见列表名次 × 桶数 ÷ 列表长度”改成固定距离带；相机用 128 方块格稳定锚点。少量瓦片进出视野不会移动其他瓦片的距离带边界。
- 同一显存页按固定 16 MiB 区域分组，区域内按分配偏移排列。命令缓存绑定 page/bucket/region/part，局部改变只重编码相应区域；原有世界坐标命令、morph 时间参数和完整 pass 复用继续使用。
- 未使用命令区域保留最多 2 秒，每套计划最多 64 个近期区域、约 32 MiB；预算同时计算命令 CPU/GPU 存储、数组容量和引用网格的保留量。准备条目另设 2 秒、128 项、16 MiB 上限。正在使用的绘制数据单独受已有驻留预算控制，这些数值不是整个预测系统的内存上限。
- 页、网格、归属范围、材质及动态网格版本继续检查；失效区域及过期的不活动直绘/Hi-Z 计划释放，防止缓存延长旧网格生命周期。

**当前帧 Hi-Z 与收益策略**

- 普通不透明 MDI 通道从每距离桶重建改成最多两次：先使用当前帧真实深度，在近距离组绘制后再更新一次。减少更新只会降低遮挡拒绝率，不使用旧视角的深度证明。
- 连续页面批次共享过滤阶段和屏障。八桶纯 MDI 回归实际记录 hizBuilds=2、filterBarriers=2。混有直接回退绘制时仍需必要的 flush，因此不能把两次屏障当成所有场景的硬上限。
- 收益比较与可见性更新分离。持续运动保留最近胜出的策略；视角安定 12 帧后重新比较。候选四边形工作量、材质与分辨率变化仍可触发比较。每帧仍以当前相机执行剔除。

**后台准备和原子交接**

- 新增一个有界需求准备任务，对不可变视角、目标与瓦片快照计算需求分类、父子/相邻依赖和近期可见性。最多一个任务在途；结果只在布局、目标、focus 和世界代次仍匹配时接受，大幅转向或传送的旧分类不能发布。
- 需求结果准备完成后才刷新队列。等待同一后台任务的 tick 不再因持续转向反复执行全套队列排序；完整规划的快照在 idle 目标合并后提交，避免提交即过期。
- 接缝连接、边界掩码和接缝 pass 数据打包移到单个后台事务。渲染线程只检查完成状态，不 join；两个接缝集合、地表/feature 掩码、绘制成员和父子归属一起发布。
- 结果就绪前保留旧的完整地形和 GPU 数据。已发布网格的替换使用新的 GPU 对象，旧对象延迟退休；等待期间暂停下一轮可选上传，限制旧新并存到当前上传窗口。使用原有每轮最多 16 瓦片、4 MiB、约 2 ms 软预算，单个超大首瓦片仍允许前进，不能解释为硬显存上限。
- 客户端可绘制快照与 Voxy 边界判断也以已发布状态为准。重置后丢弃旧世界结果；退出世界后即使不再轮询，已完成及正在完成的废弃任务也不继续持有结果快照。任务失败保留旧画面并可重试，不直接关闭整条预测渲染。

**覆盖与缓存维护**

- 原版编译覆盖按水平列缓存。块更新 Mixin 标记受影响列，未知/未编译列继续轮询；完整且未变的列跳过重复 section 检查。
- 移动覆盖窗口复用重叠范围的状态与边缘采样，只重采样新边缘、邻居覆盖变化及脏列。块状态读取仍留在客户端线程，后台接缝只读取不可变输入。
- 3D 覆盖纹理尺寸不变时复用分配并更新变化包围区域；没有变化就不上传。窗口重锚需要搬移内容，但不重新分配相同尺寸纹理。
- 归属版本在相机跨格时使用全局动态版本，不再遍历整套过滤缓存更新每条记录。局部覆盖变更仍立即撤销相应证明。
- manager 的父级覆盖失效通过空间索引查询相关后代；CPU 冷缓存维护采用每片最多 64 瓦片、约 1 ms 的扫描，退休最多 8 瓦片并再次检查安全回退。
- 快速移动期间两版统一完整规划频率、恢复检查量和可选细化并发；缺失覆盖继续优先，望远镜专用细化保留独立需求。

**验证结果**

| 平台 | CPU 回归 | OpenGL 回归 | 失败 / 错误 / 跳过 | 构建 |
| --- | ---: | ---: | --- | --- |
| NeoForge 1.21.1 | 201 | 11 | 0 / 0 / 0 | jar 成功 |
| Forge 1.20.1 | 199 | 11 | 0 / 0 / 0 | reobfJar 成功 |

新增及调整回归验证了：转出/转回区域无需重编码和上传；只改一个区域就只重编码该区域；过期区域释放引用并在返回时恢复；缓存绘制颜色与深度一致；两阶段 Hi-Z 保持保守性；异步结果等待时保留旧 GPU 并在就绪后整体交接；世界重置、版本失配和失败任务不发布旧结果；需求结果在后续 tick 生效；覆盖纹理只改变一个 texel 时只上传一个字节，窗口重锚保留相同世界位置的覆盖；重叠窗口边缘样本复用。

普通与 Iris 着色器回归包含真实/预测深度交接、部分覆盖与撤销、水面、植被、morph、望远镜视野、接缝以及外部 OpenGL 状态恢复。OpenGL 使用隐藏测试上下文，没有启动 Minecraft 客户端。测试中的合成 GPU 时间不能作为真实 FPS 或本轮修改前后的同场景收益。

包检查包括 ZIP 完整性、0.3.5 平台版本、Java class 版本、后台任务类、Mixin 注册、五平台原生库与源资源一致、未混入测试类。Forge 已核对新覆盖 Mixin 的 SRG refmap 和嵌套 LZ4；NeoForge 使用 Mojang 目标名。目标签名与打包校验不能替代用户整合包的实际启动测试。

**仍保留的主线程工作与适用范围**

完整四叉树规划、目标/优先级合并、实际队列接纳、快照交接、必要块状态读取及 OpenGL 上传/资源管理仍在客户端线程。原版掩码仍周期遍历水平列获取 chunk identity；GPU 驻留 census 和部分退休/压力处理仍有周期性扫描。接缝事务在发布时仍需要更新 GPU 掩码与缓冲，后台化没有消除这些必要上传。

这轮实现了固定区域命令复用与后台准备，没有替换成完整 Voxy GPU 层级遍历。Iris 的专用提交仍逐瓦片处理；普通 MDI 的分桶、Hi-Z 收益不能直接套到 Iris 专用路径。Iris 可受益于通用的接缝、需求、覆盖及准备缓存优化。
