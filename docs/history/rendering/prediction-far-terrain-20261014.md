**远景粗网格覆盖优化与验证（2026-10-14，VSS 0.3.5）**

本轮保留了一个有减面和独立 GPU 测量支持的修改：原有显示 LOD 策略完全无法生成粗表示时，补尝试一次按实际高度保护水、模型与边界的构建。旧逻辑保护整根 XZ 列，导致远低于水面的海床等几何也无法简化。新增策略让相距足够远的地形可以生成粗网格，继续使用原有 Voxy 风格扫描合并。

NeoForge 1.21.1 与 Forge 1.20.1 同步，版本维持 0.3.5。相比 `gpu-selection-retained-20261014` 交付，两边 JAR 都只有 `PredictionDisplayGeometry.class` 的生产字节码改变。没有推送 GitHub、替换实例 JAR 或启动客户端。

**实现和保护条件**

构建先执行原有策略；已有可用粗表示的网格保持字节一致。只有全部档位被拒绝、且确实存在受保护区域时，才补做一次高度保护构建。每个保护单元保存所有相关几何的最低与最高 Y；多个对象共享单元时使用覆盖它们的保守高度范围。保护裕量包含当前档位的最大垂直位移及额外 1 方块，横向移动路径也检查保护体积。

水和岩浆可以使用独立于 XZ 的 fine-Y 编码，本轮按真实编码读取保护高度。原始几何和水面保持原样，外边缘继续精确保留。原有完整归属、morph、近处、投影误差和滞回规则继续控制提交。构建仍要求至少减少 64 面、单表示不超过原不透明面的 65%，所有附加表示合计不超过原不透明面的一半。没有增加渲染线程上的逐面扫描。

源几何仍按原有格式写入磁盘缓存，显示计划继续只保留范围和误差元数据，压缩、上传后的原坐标不会通过显示计划留下额外引用。无须清空预测磁盘缓存；新包恢复或生成网格时会构建显示表示。

**独立 OpenGL 测量**

显卡为 NVIDIA GeForce RTX 4070 Ti SUPER，OpenGL 4.6，驱动 572.70。两平台依次执行测试。使用 11 个选定历史网格，包含 4 个原有表示控制和 7 个新增回退表示用例；这些用例用于检查具体问题，并不是随机抽样的整个世界。

测试使用生产的紧凑上传、地形着色器和 MDI 路径，保持同一命令数。每个网格重复提交 64 次，24 轮预热后进行 81 轮交错测量，以 OpenGL 异步时间查询记录 GPU 时间。选档采用 4,096 或 8,192 方块距离、900 像素尺度、2 像素误差。实际绘制使用固定的较近诊断相机及替代图集，使颜色、深度和索引错误可见；该测试隔离粗几何的提交成本，不包含完整 Minecraft 帧或整套 Hi-Z 路径。

**后台构建和存储代价**

新增回退会增加后台工作。NeoForge 的 11 个网格经 8 轮预热、25 轮交错测量后，7 个新增回退用例原构建中位数约 9.6～11.1 ms，新构建约 19.0～31.1 ms；每次构建额外分配约 3.17～3.94 MiB 临时对象。已有表示控制的分配量基本一致。这里测的是显示表示构建子阶段，不是整块地形生成总时间，也不是渲染线程耗时。

完整语料的附加表示从 6,473,205 面增至 8,881,352 面。若按规范格式每面 48 字节计算，额外增加约 110.24 MiB；此值未压缩，也不含元数据及驱动分配，不能当成实机 Java 堆或 VRAM 的增量。11 个 GPU 用例的紧凑有效负载合计从 5,891,024 字节增至 7,024,096 字节，约增加 1.08 MiB；这是有效负载，不是显存页或驱动的总占用。原有 CPU 压缩、驻留预算和回收规则继续生效。

该修改用更多后台构建和有界表示存储换取远景绘制减少，近景不会获得同等收益。诊断时可用 `-Dvss.disablePredictionHeightProtection=true` 关闭本轮新增回退；该表示在构建时生成，因此切换参数后需重启。正常使用无须添加该参数。

**回撤和交付检查**

本轮回撤了“只追加地形并共享原植被范围”的试验：额外减面小、构建更慢且部分选档退步。直接用高度策略重建全部既有表示也因部分面数退步回撤；更细的回退格网因远处收益或预算退步回撤。最终只保留原本没有粗表示的网格回退，继续使用原格网与原接纳条件。
