# 真实区块接管预测体素修复

版本：0.3.7。构建标识：`20261102-climate-height-authority`。

## 问题与原因

玩家反馈错误预测在靠近时消失、离远后重新出现。原有合并逻辑优先保留真实非空气方块，但没有一致记录本地真实区段中的空气；粗 LOD 因而可能继续显示已经过时的预测。部分队列退出路径还把任务受理或完成当成了整列真实数据已经写入，重新进入世界时也缺少可靠的空气接管记录。

## 修复行为

- 接管范围精确到成功写入的 16×16×16 真实区段；以 Voxy 原生 `WorldUpdater.insertUpdate` 成功返回作为依据，覆盖本地与服务端输入。
- LOD 0–4 的中心与六个邻接面使用相同的接管规则。已知真实空气会覆盖预测，未知高度与邻近区段保留预测，已有真实方块继续优先。
- 丢弃、队列上限退出、没有实际提交任务、写入异常均只释放对应任务，不授予真实空气接管权限。兼容直接写入与已验证的单层 `processTask` 委托写入布局。
- 切换光影或重建渲染器保留真实接管证据；退出世界撤销旧会话授权，迟到回调不能污染新世界。
- 接管记录随原生区段保存和加载。只有原生保存成功才留下记录，读取成功且对应 LOD 的原生数据长度与 SHA-256 一致后才恢复。
- 全空气区段及仅接管记录变化也排入原生异步保存队列，避免重进后丢失证据。查询接管状态仅访问内存。
- 运行时缓存失效局限于受影响区段与关联边界；登记证据的全局锁不包裹渲染缓存失效或原生保存排队。

原生 Voxy 数据格式保持兼容，附加证据使用独立记录。旧数据库没有这类证据的区域不会被推断为完整真实区块；实际区段重新录入后自动建立可靠记录，无需删除原有数据库或存档。

## 验证范围

NeoForge 与 Forge 各通过 125 项接管、调度和兼容回归，以及 17 项持久化与原生写入检查；两组存在重叠用例，不作为独立测试数累计。

针对 13 个实际 NeoForge / Forge Voxy 包，检查了 26 个存储与世界身份目标、所有真实写入点和字节码栈；覆盖真实 Sponge Mixin 应用、原生保存方法执行、异常原样重抛、全空气保存、负坐标与扩展高度、旧会话回调及加载恢复。

Fabric 1.20.1、1.21.1、1.21.11、26.3 进行了代表版本接管回归。另在 26.3 的运行环境中对 5 个实际 Fabric Voxy 包验证存储、身份及写入契约，17 项相关检查通过。十个目标的最终编译与包核对由统一发布流程完成。

本轮为代码回归、真实依赖字节码与离线执行验证，尚未复现玩家报告的原始存档画面，也未测量本修复对实际游戏 FPS 的影响。其它对话已完成的气候与高度计算优化一并保留，其计时收益不计作本修复收益。
