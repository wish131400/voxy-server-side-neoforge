# 渲染线程与重复调度修复（2026-10-10）

> 历史记录：保留当时的实现、输入与验证结果，不能据此判断当前版本的渲染架构、配置或兼容范围。 当前说明见 [文档目录](../../README.md)，相关旧报告见 [历史索引](../README.md)。

本轮依据 `prediction-thread-contention-profile-20261010.md` 的实际客户端采样修复代码，并同步至 NeoForge 1.21.1 与 Forge 1.20.1。原采样有效窗口约 39.62 FPS，渲染线程单核 CPU 占用约 89.5%；渲染准备、归属过滤、可见性准备与重复任务调度均有热点证据。本轮没有重新安装客户端或采集修复后的游戏 FPS，测试结果不能换算为实际帧率提升。

## 修改内容

1. **预算拒绝后的重复调度。** `PredictionCpuBudget` 在实际执行配额被拒绝后，对紧急覆盖、普通细节两个通道分别建立 100 ms 的共享预约退避。所有管理器都读取这个状态；任意执行租约释放后立即解除退避。细节通道在额度已占满或两秒渐进恢复间隔尚未结束时，直接在入队前拒绝。保留有界队列与执行时的最终配额检查，避免单工作线程断粮，也不会绕过并发限制。
2. **配额恢复被旧计时拦住。** 移除 `PredictionTileManager` 在 CPU 预约失败后附加的每地块 10 ms 期限，改由共享预算处理退避。回归测试发现，旧期限可能使另一个管理器在配额释放后仍无法立即开始；现已修复。内存压力、生成失败等其他重试规则保留。
3. **移动时重复扫描归属几何。** 先用整个网格的三维包围范围排除与 Voxy 范围无交集的对象；静态覆盖证明为空时直接返回原绘制范围。部分覆盖时缓存已覆盖几何段的索引，只对这些段做距离判断和范围扣除，不再遍历全部未覆盖段。保持输入范围顺序，树木等装饰仍不能借用地面列证明被删除。
4. **原地 morph 更新的缓存正确性。** 归属过滤缓存增加网格提交版本检查，避免相机不动时修改 morph 高度后继续复用过期剔除结果。Voxy 覆盖撤销仍在当前更新恢复预测几何。
5. **局部上传与移动叠加时全场景失效。** `Scene.prepare` 使用现有驻留变化日志中的受影响地块及父子归属范围。只要布局、视距和归属视角条件稳定，局部上传不再让全部可见候选进入归属重算；相机移动仍更新面朝向、视锥和距离边界，接缝按变化区域更新。
6. **提交计划整体重建与临时对象。** 间接命令缓存不再因为全局驻留／归属版本变化直接清空；提交时继续逐项验证 Draw、GPU 分配、绘制范围、morph 和材质等状态，发现真正变化才转入重建。材质／程序变化仍触发失效。PreparedPass 复用条目和临时映射容器，只有实际范围映射改变才发布新映射，避免把无效更新继续传给显存页分组。水面继续按当前相机排序。

这些改动处理的是预测渲染与客户端生成调度的重复工作；不涉及服务器 `/vss chunky` 的速度优先策略。

## 验证

| 平台 | CPU 回归 | GPU 回归 | 打包 |
| --- | --- | --- | --- |
| NeoForge 1.21.1 | 202 通过，1 条件跳过 | 7 通过，1 条件跳过 | jar 成功 |
| Forge 1.20.1 | 200 通过，1 条件跳过 | 7 通过，1 条件跳过 | jar + reobfJar 成功 |

两平台均无测试失败。GPU 测试使用 RTX 4070 Ti SUPER 的隐藏 OpenGL 上下文，包含生产提交路径的颜色／深度对照、Hi-Z、MDI、透明水面、接缝、覆盖交接、GL 状态恢复，以及 shader/Iris 路径的回归夹具。它们不是完整整合包中的游戏实测。

新增或加强的检查包括：

- 连续 10,000 次预约请求在已拒绝且未恢复的状态下均不入队；租约释放立即重开预约，超时后可做有限重试。
- 跨管理器完成、异常、暂停、关闭、执行器拒绝等生命周期释放配额；高压力下仍按原有恢复间隔完成细节。
- 100 组相机、半径与 morph 条件下，稀疏归属扣除与独立逐面参考结果一致，并保留不按坐标排序的输入范围次序。
- 原地改变 morph 高度后立即恢复需要显示的几何；覆盖撤销、窗口迁移、高度变化继续通过已有回归。
- 局部上传与相机移动／旋转发生在同一帧时，只增加一个受影响地块的场景访问；稳定邻居的 Draw 被复用。
- 无关驻留版本变化仍逐项命中原有提交计划，上传批次为零，像素输出保持一致；真实成员、排序和 morph 变化仍与重新编码路径一致。
- PreparedPass 在无关上传时复用条目对象和已发布范围映射，实际植物等级／网格替换时仍更新范围。

每个平台有两项条件跳过：`PredictionSpatialReplayTest` 缺少指定的录制网格输入；`PredictionVoxyDepthConventionGpuTest` 未传入实际 Voxy JAR 路径。通用深度／交接回归已运行，不能将条件跳过写成通过。

JAR 已检查 ZIP 完整性和全部五种平台的 Rust 原生库资源。NeoForge 本轮涉及的 40 个主类／内部类与隔离构建编译输出逐字节一致；Forge 完成生产重映射，并检查这些类均已打包。
