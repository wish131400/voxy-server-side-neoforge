# VSS 0.3.6

> 历史记录：保留当时的实现、输入与验证结果，不能据此判断当前版本的渲染架构、配置或兼容范围。 当前说明见 [文档目录](../../README.md)，相关旧报告见 [历史索引](../README.md)。

构建标识：`spyglass-active-20261028`。

修复望远镜放大后，只提高已有任务优先级、却不主动为目标区域建立精细采样需求的问题。现在按实际画面的投影和可见范围建立采样目标，交给现有生成队列、Rust / Java 计算和缓存发布流程；Voxy 继续负责构网、LOD、遮挡、上传与绘制。

窄视角下的小幅转向也会刷新采样需求，避免放大后准星已经移动，加载目标还停留在旧方向。已有精细数据可以直接加入目标记录，完整的更细子区域也不会为了缺少父块而重复生成父层。

修复粗父级预测体素越出 VSS 预测范围后仍被 Voxy 显示的问题。完整地形和植被统一应用预测边界，配置距离内的区域继续申请采样，范围外的粗父块不再表现为长期停留的大平板。真实 Voxy 数据在合成时仍按原有覆盖规则保留。

预测边界按 64 方块格稳定更新，并保留覆盖整个配置半径的裕度。移动和调整视距只撤销受边界影响的体素及邻面缓存；相同小格内的移动复用边界缓存，传送时通过空间索引处理受影响区域。边界计算和渲染桥接通知在体素源锁外执行。

包含现有植被缓存接续修复：未完成的局部植被只贡献实际已有方块，不能以未知空白遮住父层植物；回收完整植被时需要完整父层接续。

提供 NeoForge 1.21.1 和 Forge 1.20.1 两个版本。离线回归覆盖生成、细化、边界、缓存、传送及既有 Voxy 兼容矩阵。未替换运行整合包，安装后的画面、加载延迟和帧率仍需实机确认。
