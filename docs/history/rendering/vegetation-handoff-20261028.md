# 预测植被的 LOD 交接修复

> 历史记录：保留当时的实现、输入与验证结果，不能据此判断当前版本的渲染架构、配置或兼容范围。 当前说明见 [文档目录](../../README.md)，相关旧报告见 [历史索引](../README.md)。

构建标识：`vegetation-handoff-20261028`。支持 NeoForge 1.21.1 和 Forge 1.20.1。

本次修复预测树木在后台细化期间反复消失、重新出现的问题。即使玩家站着不动，后台仍会恢复缓存、生成植被并发布不同精度的数据，因此也可能触发旧的错误交接。

旧逻辑把“细一级缓存里已有部分植物”当成“该区域植被已经完整”，由它接管整个水平区域。缓存没读到的树会暂时被隐藏，后续生成完成后又恢复。此前的保留逻辑主要处理同一瓦片的地形更新，未解决不同 LOD 间的不完整结果交接。

现在，不完整结果只补充已知的植物方块；重叠位置优先使用细一级的方块。完整植被结果仍有明确的区域归属，完整空结果可以移除先前的树。地形、建筑和真实区块的优先规则继续独立处理。

同步修复了局部更新通知和缓存回收：不完整子级不再阻断父级植被的更新通知；视距内回收带植被的记录时，需要可接替的完整父级植被，避免撤掉唯一的数据来源。完全离开当前视距的旧区域继续正常回收。

两个版本使用相同的修复。现有地形和植被缓存可以继续复用，无需清空。发布包提供标准文件名，构建标识记录在 JAR 清单与发布校验记录中。

回归验证覆盖不完整父子级交接、缓存移除和重到、重叠方块优先级、完整空结果、负坐标、不同原生 LOD、邻面更新、地图投影及缓存回收。自动回归不代替整合包和光影环境中的实际画面复测。
