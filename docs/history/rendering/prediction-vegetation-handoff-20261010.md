# 真实地形／Voxy 与预测 LOD 的植被交接修复（2026-10-10）

> 历史记录：保留当时的实现、输入与验证结果，不能据此判断当前版本的渲染架构、配置或兼容范围。 当前说明见 [文档目录](../../README.md)，相关旧报告见 [历史索引](../README.md)。

本次针对移动时交界处树、树干和草突然消失又出现，同步 Forge 1.20.1 与 NeoForge 1.21.1，版本保持 0.3.5。

## 已确认的代码问题

原路径将预测地形和地表装饰共用一个归属。Voxy 的二维已入库列索引可以证明该列已有真实数据，但不能证明本帧对应高度的树冠、草或建筑构件已经画出。原 CPU 提交过滤与 shader 的地形高度容差会因此提前删除预测装饰。另一方面，更细预测瓦片的地面先到达时，会夺走仍由旧父瓦片提供的植被；同一 footprint 的地形升级也可能以临时无植被的网格替换已有完整表示。

## 本次修改

- 网格生成时明确标记地形结束后的地表装饰。树叶、树干、草和模板装饰共用 feature 标记；不依赖 cutout 材质猜测。四边形打包、空间排序、压缩、GPU dictionary 和显示 LOD 保留标记。贪心合并不跨越地形／装饰归属。
- CPU 的 Voxy 列索引过滤继续删除可确认的地形范围，装饰送入实际深度判断。普通和 Iris shader 为装饰保留正常遮挡／等深交接，排除针对地形的二维列硬剔除与宽高度容差。已编译的原版 section mask 继续生效。
- 复用现有 R8 cell mask，分别使用 128 表示地形归属、64 表示装饰归属，低四位保留地形接缝方向。普通与 MDI 路径采用同一规则。没有增加新的独立渲染层。
- 预测装饰选择优先使用完成的、已经上传的表示。更细地面可先接管，旧父瓦片的装饰继续绘制；新装饰完成并上传后交接。完成但没有装饰的区域同样可以接管，清除旧预测树草。
- 同一 footprint 的地形升级，在构建工作线程中复制旧装饰进入新地形 payload，排除新网格中的临时装饰，避免同槽 GPU 替换产生裸地。临时继承的网格不写入 finished mesh cache，后续正常表面任务仍继续运行。
- CPU 裁退后仍有待完成装饰接替时，保留必要的已上传父表示。交接完成、范围缩小、维度重置或明确 Voxy 整瓦片接管时，仍走原有释放路径；现有 GPU 驻留预算继续管理这些网格。
- 整瓦片 Voxy 接管保留完整高度和周围一圈 settled 列校验，并采用进入半径减 64 方块、保持半径减 32 方块的迟滞规则。这两个半径以原有扣除两区块的 Voxy 半径为基准。索引缺口立即撤销接管，新数据未稳定前也不能重新接管。

装饰交接仍以已有 cell mask 和网格完成状态为单位，没有新增整棵树组件系统。Voxy 整瓦片退休仍使用稳定索引与范围校验；边带内才保留当前帧逐像素深度交接，不能将索引描述为“本帧整棵树已渲染”的证据。

## 缓存兼容

finished mesh 格式版本从 11 升为 12，避免旧记录缺少装饰标记。旧 finished mesh 需要重建一次；基础地形、placement 数据和 Voxy 数据库无需删除。已有完整空装饰、城市提示恢复和脏地块更新仍有回归覆盖。

专用测试 source set 与输出目录用于避免共享工作区的其他测试输出冲突。覆盖新旧预测地面／装饰交接、延迟 GPU 上传、完整空装饰、CPU 裁退、压缩恢复、索引撤销、小幅边界往返和贪心合并保留归属。GPU 使用真实 OpenGL 上下文与生产 shader，检查普通／Iris 标准与 reversed-Z，以及直接／MDI 提交。

验证结果如下（每个版本的 CPU 数量包含交接回归与 12 项缓存补充检查；跳过的用例单独列出）：

| 版本 | CPU 通过／跳过／失败 | 完整 GPU 通过／跳过／失败 | 植被直接／MDI 专项 |
| --- | --- | --- | --- |
| NeoForge 1.21.1 | 107 / 2 / 0 | 5 / 1 / 0 | 通过 |
| Forge 1.20.1 | 107 / 2 / 0 | 5 / 1 / 0 | 通过，补充独立运行 |

GPU 硬件为 NVIDIA GeForce RTX 4070 Ti SUPER。CPU 跳过项是缺少外部网格 corpus 的 benchmark，以及只在 GPU 开关下执行的森林上传用例；森林上传已在 GPU 任务运行通过。GPU 跳过项需要显式提供外部 Voxy JAR 的 final-blit 深度约定测试。本次没有把跳过项计为通过。

Forge 最终构建也修正了新缓存代码中两处 `DataResult.getOrThrow` 的 1.20.1 API 写法，保留编码错误时拒绝记录的语义。两个版本的缓存读写、城市完成状态和旧数据恢复回归通过。


本轮没有替换客户端、启动游戏或采样实际世界。自动化 GPU 用例和微型场景不等同于原整合包现场测试，也不提供 FPS 改善保证。手动测试应在原问题区域沿真实地形／Voxy 边界往返，分别检查普通画面、光影与望远镜，观察是否仍有先空掉再补回的间隙。
