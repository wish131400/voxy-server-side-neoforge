## 画面与结论范围

用户录像 `2026-10-20 20-32-36.mkv` 长约 39.7 秒。进入世界后，近景森林、河流之外出现很大的绿色矩形顶板、灰色侧面和台阶；后续细节逐步出现，大板多数退去，但岸线和局部山体仍可见断面。

本轮确认了两个代码问题：

1. **父 LOD 来源标记与侧壁检查标记冲突。** 已用行为回归复现并在两平台修复。
2. **超大粗格仅按中心点选择归属。** 已在生产 `resolveCoverage` 上直接复现重叠与过度撤销两种情况。该缺口尚未修改，不能将第一项的小修视为录像全部异常已经修复。

这些证据支持继续处理粗预览与细地形的交接。没有取得录像每个异常像素的绘制来源，尤其不能断言每条灰断面都由 VSS 生成；部分也可能是 Voxy 的边界侧面被露出。

## 已修复：来源标记冲突

`ClientColumnSample.FLAG_PARENT_LOD` 原为 `1 << 25`，与 `PredictionWallEvidence.CHECKED` 重合。

真实捕获或精确生成的列经过侧壁检查后，可能被 `reusableFor`、`reusableForDisplay` 当作父级汇总列拒绝复用。反向地，携带侧壁检查位的近似预览，也能绕过 `PredictionParentLod.reduce` 的来源校验，被误认作可继续归约的父级样本。这破坏了“精确来源才可构建同源父层”的约束。

修复将父级标记移到空闲 bit 18。保留已经持久化的侧壁 bit 25。检查了 Java 与 Rust 列标记分配；PackedMesh 使用的是另一种记录格式，不随本修复改变。

同源父级的构建结果不写 terrain 成品缓存，且对应的 `cacheAccepted` 为 false，不写独立 mesh 成品；父级证明也是会话内数据。因而本次标记迁移不要求清除世界缓存、改变网络协议或迁移持久化的侧壁证据。

新增两项行为回归：

- 经过侧壁检查的真实列，仍可用于预览、精确生成与显示复用。
- 经过侧壁检查的近似列，不能冒充同源父级输入。

改前这两项都失败；修改标记后通过。原有父层、洞穴侧壁、外部占用与缓存回归也通过。

## 已复现、尚未修改：粗格与归属网格分辨率不一致

8192 方块父瓦片的初始网格可为 8×8，即每个源格覆盖 1024×1024 方块。预测最小瓦片只有 64×64。

`PredictionRenderer.resolveCoverage` 当前仍以源网格大小构造掩码；一个粗格仅查询中心位置归属，随后决定整格保留或撤销。它不能表达粗格内的局部细瓦片。

临时诊断程序通过反射调用生产方法，使用负坐标、一个粗父和一个已纳入渲染快照的细子，得到：

| 细瓦片位置 | 粗格决定 | 结果 |
| --- | --- | --- |
| 粗格内部、避开中心 | 整格保留 | 细瓦片的 4096 平方格同时被粗格覆盖 |
| 正好包含粗格中心 | 整格撤销 | 其余 1,044,480 平方格的父层回退被一起撤销 |

这证明现有掩码可以造成与录像类似的“细节出现但粗顶板仍覆盖”，也说明不能只把判断改成“有细块就删除整个粗格”。中心点算法在 HEAD 中已经存在，属于旧缺口；最近的交接路径变动可能使它更明显，不能把它描述成最新 API 新增的算法。

后续修改需要让归属裁切能表达最小瓦片边界，而不依赖原始高度采样间距。地形、掩码与接缝还要保持同一版本交接。当前帧没有可用替代物时必须保留父层，替代撤销后必须恢复。不要新增按相机距离、任意深度像素或全列索引无条件删面的补丁。

临时诊断源与日志位于 `tmp/video-regression-20261020/probe`、`coarse-cell-probe.log`，不编入主 JAR。

## 缓存网格检查与排除范围

只读检查了录像位置附近的 856 份 terrain 网格与 833 份活动成品 mesh，未改动存档缓存。与可用真实区块的高度对比，没有发现细网格普遍高出几十格的现象。

确有不准确的粗预览实例：`lod1 (-33,-14)` 在 `(-4176,-1712)` 记录高度 -44，而同坐标细网格与另一层网格为 96；该预览带 `APPROXIMATE | SURFACE_ONLY`，成品可包含约 142 格高的侧壁。该点没有真实 MCA 可对照，也没有证据证明录像恰好提交了这一份网格，不能将其作为唯一根因。

对含明显侧壁的 49 份真实缓存 mesh，共 613,906 个 quad，执行当前生产颜色字典、矩形编码、水体与不透明拆分后精确解码回放：**0 个记录不一致**。这缩小了“这些网格被无损编码写坏”的嫌疑；不覆盖其余缓存、未落盘的根预览，也不等于实际游戏 GPU 画面验证。

现有 GPU 夹具涵盖生产 MDI/直绘、紧凑编码、前景与后方切面、水体、植被深度、接缝驻留。全部通过，但未覆盖上述 1024 格粗源格与局部细瓦片的混合归属。通过数不能用来声称录像已修复。
