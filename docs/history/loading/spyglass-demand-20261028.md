# 0.3.6 望远镜细化调度修复

> 历史记录：保留当时的实现、输入与验证结果，不能据此判断当前版本的渲染架构、配置或兼容范围。 当前说明见 [文档目录](../../README.md)，相关旧报告见 [历史索引](../README.md)。

构建标识：spyglass-demand-20261028。

修复大量远景细化请求堆积时，望远镜已经放大但目标区域迟迟没有新增细节的问题。

- 保存因队列已满或优先级变化而推迟的目标记录，按水平位置与精度去重；待执行任务仍最多为 4096 个。记录随目标离开预测范围或关闭世界清理。
- 视角变化时，将等待目标一并参与后台排序；重新接纳当前画面中的目标，并保留被替换目标的记录。
- 细化任务完成后自动补入等待目标，避免依赖遍历大量三维节点后才发起的重复请求。
- 同步更新加载器使用的目标快照，覆盖后台排序和任务完成触发的目标变更。

继续由 Voxy 决定细分并负责构网、LOD、遮挡和绘制，沿用现有 Rust / Java 地形与完整植被生成。

本次提供 NeoForge 1.21.1 和 Forge 1.20.1 两个构建。尚未替换正在运行的整合包文件，安装后的实际加载延迟与帧率需再次对照。
