# 预测加载独立开关（2026-10-14）

> 历史记录：保留当时的实现、输入与验证结果，不能据此判断当前版本的渲染架构、配置或兼容范围。 当前说明见 [文档目录](../../README.md)，相关旧报告见 [历史索引](../README.md)。

新增客户端“预测加载”设置，默认开启。它将预测任务加载与预测 LOD 显示分开控制，两个平台行为一致。

## 玩家用法

在视频设置的 VSS 预测页中，保留“VSS 远处预测”开启，关闭其下方的“预测加载”，然后应用设置。当前内存中已完成的预测远景继续绘制；重新开启“预测加载”即可继续，不需要重连世界。

| 预测远景总开关 | 预测加载 | 行为 |
| --- | --- | --- |
| 开 | 开 | 显示已有远景，继续生成、细化、读取成品缓存 |
| 开 | 关 | 显示已有远景，暂停新增预测任务 |
| 关 | 任意 | 隐藏预测远景并暂停预测任务；保留独立的加载设置值 |

客户端配置文件 `config/vss-client-config.json` 示例：

```json
{
  "enablePrediction": true,
  "enablePredictionLoading": false
}
```

旧配置没有新字段时，默认仍加载预测远景。显式关闭的设置在配置校验、保存和下次启动时保留。界面应用后的下一次客户端 tick 更新任务状态。

暂停只保留当前会话已加载的几何，并不把磁盘中所有缓存自动加载到内存。暂停期间进入尚未加载的区域不会自动补充预测覆盖；重进世界后若仍处于关闭状态，需要开启加载才能恢复磁盘中的远景。

## 实现范围

- 配置增加 `enablePredictionLoading` 和中文配置说明。
- NeoForge 的 Sodium 0.8、新旧选项接口，以及 Forge 的 Embeddium 选项页均增加独立复选框和中英文提示。
- 维度首次初始化、新预测任务入队、地形细化、成品网格缓存恢复都遵守加载状态。
- 复用已有暂停机制：中断运行中的生成，在安全检查点取消工作；取消排队任务并释放 CPU 租约，通过版本检查拒绝过期结果。
- 保留已有 CPU 网格、绘制快照及当前已上传几何。恢复时从已有数据继续规划，而不是重置整个预测世界。
- 保留渲染相机更新、屏幕空间 LOD、资源维护和真实 Voxy 覆盖交接。暂停状态不做新的城市提示请求或望远镜未覆盖区域的地形采样。
- 真实 Voxy 区块的本地导入、服务器接收和真实数据维护继续由各自开关控制；该设置不控制服务端 `/vss chunky`。
- 客户端诊断和渲染采样报告增加加载状态，方便区分“预测仍显示”和“后台加载已暂停”。

已经开始的初始化和真实数据维护可能继续完成必要清理。这个设置不承诺 VSS 所有 CPU、磁盘和网络活动归零，也不移除已有几何的 GPU 绘制成本。

## 验证

Forge 1.20.1：16 个测试类、124 项测试，全部通过。

新增测试通过真实工作线程切换配置，验证：

- 原有配置默认开启，保存的关闭状态不会被迁移重置。
- 关闭加载时主显示开关仍开启，同一个粗网格和绘制快照保留。
- 正在执行的细化和必要初始覆盖可以取消，队列配额释放。
- 关闭期间调用生成、缓存恢复入队和 tick 不会开始新任务。
- 重新开启可以完成细化，取消不会留下失败重试冷却。
- 非当前维度保持暂停，加载设置不能越过预测总开关。

同时运行原有 CPU 租约生命周期、内存生命周期、过期缓存恢复、覆盖交接、可见细化和植被配置回归。构建成功，Forge 已完成 `reobfJar`。
