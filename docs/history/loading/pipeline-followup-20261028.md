# 0.3.6 预测流水线优化

> 历史记录：保留当时的实现、输入与验证结果，不能据此判断当前版本的渲染架构、配置或兼容范围。 当前说明见 [文档目录](../../README.md)，相关旧报告见 [历史索引](../README.md)。

构建标识：pipeline-followup-20261028。

- 分离维度可写高度与噪声生成高度，修复下界合法高位植被写入被原生代理拒绝的问题。越界批次仍整体拒绝，错误信息包含实际坐标与范围。
- 粗 LOD 反向归并，只转换最终保留的区间；保持原覆盖顺序、空气洞、液面及负高度语义。单根细列保留直接转换。
- 转换缓存为近期复用的列提供一次保留机会，单次扫描最多一圈；维持原内存上限、退场和映射器释放逻辑。
- 规划候选按变化分片合并，宽限时间刷新不重建成员快照；仅有调用需求的映射保存成员快照。
- 完成 Rust 显示采样阶段测量，细分密度边界、表面材料、群系及颜色开销；复用准入检查已经精确解析的地表与水面群系，避免颜色阶段重复查询。测量开关在发布原生库中关闭。

相同固定场景、同一进程交替执行旧新算法，全部输出校验值一致。粗 LOD 的 12 次冷转换从约 145.801 毫秒下降到 81.861 毫秒，约减少 43.9%。包含 65536 个候选项的稀疏变化回放中，候选集合发布中位耗时从 16.006 毫秒下降到 0.178 毫秒。此数据属于 CPU 回放，不代表游戏 FPS 翻倍。具体结果以 validation.json 为准。

NeoForge 1.21.1 和 Forge 1.20.1 均提供标准文件名构建，包含五个平台的原生库。完整植被、生成精度、预测距离及统一 Voxy 渲染流程保持原有设置。

本次未替换整合包中的模组文件，尚未进行安装新构建后的实机帧率对照。
