# 0.3.6 新世界远景补全优化

> 历史记录：保留当时的实现、输入与验证结果，不能据此判断当前版本的渲染架构、配置或兼容范围。 当前说明见 [文档目录](../../README.md)，相关旧报告见 [历史索引](../README.md)。

构建标识：`new-world-loading-20261028`。

本次减少进入世界后远景与植被补全过程中的重复转换、查询及构网。Rust / Java 地形与完整植被计算、预测距离、统一 Voxy 渲染和现有 CPU 与内存预算继续使用。

- 粗地形转换按相邻的最多 8×8 根输出柱保存为紧凑页，共享缓存管理和内存保留记录。不同高度的 section、邻面与并发请求复用同一页。非对齐与边缘采样保留逐格精确归并，空气覆盖顺序、负高度、液面和材质保持一致。
- 查询植被和地表建筑前先计算实际归属。父层已被细地形完全覆盖时，跳过无输出贡献的特征查询、坐标解码及材质转换；局部覆盖、未完成子层及完整空植被继续遵守各自的归属顺序。
- 发布或移除数据时，按 Voxy 原生采样层级判断变化是否仍可能影响输出，共用判断结果过滤 section／邻面缓存失效与构网通知。包含相邻原生体素，保留邻面变化通知；下界等无天空光维度继续使用完整的传播光照失效范围。
- 视距改变导致层级数变化时，由任务管理器统一撤销旧计划、淘汰超出新层级范围的细化需求，再提交新布局的加载统计和调度。保留驻留地形，修复旧计划触发 `LOD level outside layout` 的路径。
- 合并植被稳定性修复：普通地形刷新保留仍有效的完整植被；真实编辑、城市或植被设置变化继续使旧植被失效。合并未完成植被时按六个坐标去重并保留顺序，同一几何使用新状态；完成但为空的记录仍能清除旧树。单独更新植被不会使地形父层证明失效。

固定压力回放使用同一组 4096 根输出柱、8 次交替高度扫描、2 个完整 section 缓存位和 1 MiB 粗柱缓存额度。旧实现转换 32768 根柱、淘汰 31071 个条目；本次转换 4096 根柱、淘汰 0 页，64 页共占 614128 字节。两个实现的完整输出校验值相同。独立进程各运行 5 轮，排除首轮后的本机耗时中位数为旧实现 90.882 毫秒、本次 23.909 毫秒；该数据仅表示固定 CPU 回放，不能换算为整世界加载时间或游戏帧率。

自动回归覆盖体素与六个邻面的一致性、正负坐标、部分采样边界、并发转换退场、内存额度拒绝、下界光照、空植被清除、父层恢复、发布通知过滤、父层植被继承和视距缩减。正式发布前同时验证 NeoForge 1.21.1、Forge 1.20.1 的模块、统一渲染及 Voxy 兼容入口，并核对源码快照、构建标识与原生库校验值。

本构建尚未替换整合包中的模组，也未进行安装后的实机加载速度对照。无需为本次升级清空预测缓存。
