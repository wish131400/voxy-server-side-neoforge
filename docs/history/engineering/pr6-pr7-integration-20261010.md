## 本地区块转换

新增客户端 `enableLocalChunkIngestion`，默认 `true`。在 VSS 的 Voxy 设置页增加“本地区块转换”，并提供中英文说明。NeoForge 同时适配新旧两套选项页接口。

关闭后阻止本地加载区块进入 Voxy 转换流程，VSS 接收的服务端 LOD 仍可进入原摄取流程；已缓存 LOD 保留。该设置目前是客户端全局设置。

服务端路径使用可嵌套的线程作用域标记，异常退出时清理标记。数据来源判断位于同步入队入口。

原 PR 在 `isIngestEnabled` 的 HEAD 无条件返回 true。此次改为只 Redirect 原方法读取 `VoxyConfig.ingestEnabled` 的位置，保留原方法的其他控制流及回放禁止写入判断。反射字段访问按配置类缓存，不在每次摄取时重新查找字段。

## 自动生成预算

| 配置 | 默认值 | 作用 |
|---|---:|---|
| `generationSnapshotsPerTickLimit` | 0 | 已加载区块和自动新生成区块的共享快照数量上限；0 不额外限制 |
| `generationSnapshotBudgetMillis` | 0 | 自动快照累计耗时的软预算，单位毫秒；0 关闭 |
| `generationPauseAboveMspt` | 0 | 平均 tick 耗时达到阈值时暂停自动新增生成任务；0 关闭 |

三项配置均已在两个仓库的配置帮助中说明。老配置缺少这些字段时保持 0，升级不会自动启用新限流。

配置精简：删除 `generationStartsPerTickLimit`。原有 `automaticGenerationStartsPerTick()` 已按 CPU 核心数与全服并发上限控制每 tick 新增生成任务；额外的手动上限只会再降低启动速度。删除字段、帮助、校验和调度分支，统一使用原自动启动控制。旧配置中的该字段由 JSON 读取忽略，加载后自动保存时会连同旧帮助项清理，不需要用户手动编辑。

保留的三项保护有独立范围：自动完成数量只约束生成结果，快照预算还覆盖已加载区块；快照时间预算累积同一 tick 的复制耗时；MSPT 暂停控制新增任务，不等同于固定并发上限。它们均默认关闭，显式 chunky 继续豁免。

计数按实际服务器 tick 更新，避免同一 tick 的请求阶段和生成交接阶段分别刷新预算。MSPT 查询读取服务器已有的平均值；Forge 与 NeoForge 分别适配毫秒、纳秒接口。

### 有限预留与进度公平性

原 PR 只要发现一个生成完成的区块，就拒绝全部已加载区块快照。此次取消这个整体否决条件：

1. 数量预算充足时，正常区块更新继续执行。已有正常快照后，最多为生成结果预留最后一个数量名额。
2. 开启时间预算时，正常快照已用到一半预算后，才考虑为生成交接保留余量。生成结果取得一次执行机会后，本 tick 剩余预算继续开放。
3. 只有已经就绪且通过已知打包容量检查的自动生成结果，才触发预留。尚未生成完成、已知无法进入打包、显式 chunky 的结果均不触发该预留。
4. 当预算每 tick 仅一个名额，或单次正常快照超过软时间预算时，记录自动生成的预算延期；下一 tick 为就绪生成结果提供一次优先交接机会，随后恢复正常更新的先执行机会。
5. 关闭服务器服务时清理暂停、计数和公平性状态，防止新服务器沿用旧状态。

现有脏列/优先请求的打包优先级继续生效。有限预留遵守共享总预算，因此小预算下的优先更新仍可能延期。

### 显式 chunky 豁免

`/vss chunky` 的生成启动、快照数量、快照时间和 MSPT 暂停均豁免新增预算。显式任务不会消耗自动生成的新增任务计数或自动快照计数。

判断针对任务自身的 background callback。注册一个 chunky owner 不会让其他普通任务绕过自动预算；同一底层生成任务若同时服务于 chunky 与普通请求，按显式任务执行。

自动任务在队列前部因预算暂停时，选择器会继续查找后面的 chunky 任务；达到自动完成数量或时间上限时，遍历仍会寻找可执行的显式任务。

诊断新增自动快照总数/耗时、正常和生成快照数量、生成预算延期状态，以及独立的 chunky 快照数量/耗时。chunky 不占自动预算，但实际工作仍计入诊断。
