# 远景重复重建与完整植被缓存修复

构建标识：`publication-repair-20261028`。版本仍为 0.3.6，同时提供 NeoForge 1.21.1 和 Forge 1.20.1。

本次调整围绕采样、父层合成、数据发布、Voxy 通知和磁盘恢复的整条调用链。

- 父层可以复用已经用于显示的细地形样本，避免任务进入队列后又因不同的资格判断退回独立生成。合成结果继续保留来源标记，不能作为精确地形或植被生成输入。
- 发布前先比较地形、样本和植被内容。相同内容完成任务收尾，同时保留有效的地形版本，避免再次触发父层刷新。
- 植被的局部变化只更新实际变化的范围；首次覆盖、植被完成状态变化、来源切换和移除仍按完整覆盖范围处理。
- Voxy 通知比较最终合成的方块、子节点占用和邻接面。内容相同时省去重复通知，真实变化分别触发构网或占用更新；通知读取不再挤占原生网格读取使用的快照缓存。
- 完整植被按有界分页保存，不再因超过 262,144 条记录而拒绝整块成品缓存。读取会校验分页数量、总量和完整性，并继续兼容上一版有效的成品缓存。
- 相同的成品体素共享待写入或已完成的保存结果。真实地形失效、生成设置变化和内容变化仍会重新写入。
- 内存回收保留当前父层合成所依赖的四个子区域，避免为了构建父层先删掉输入，随后在子区域补回时再次刷新。回收和生成共用同一精度目标；无关的低优先级细节仍可回收。
- 成品体素使用快速压缩，降低保存时占用处理器的时间，代价是文件体积有所增加。其他缓存类型保留原来的压缩策略。

本次不减少植被密度、预测距离或地形精度。离线回归和压缩对比用于验证行为及成本；实际帧率与新区域补全速度需在替换新包后重新测量。
