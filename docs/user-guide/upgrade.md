# VSS 0.3.6 使用与升级说明

[文档目录](../README.md)

支持 NeoForge 1.21.1 / Java 21 和 Forge 1.20.1 / Java 17。两个 JAR 不能互换；更新多人游戏时，客户端与服务端均使用对应平台、同一次 0.3.6 构建。网络协议仍为 53。

## 安装与升级

退出游戏或服务器后，移除旧 VSS JAR，再安装 `vss-0.3.6-neoforge-1.21.1.jar` 或 `vss-0.3.6-forge-1.20.1.jar`。保留现有配置和存档，通常无需删除 Voxy 缓存或整个预测缓存。旧记录会按来源与格式校验恢复；无法匹配的记录按需重建。

预测为 Beta，默认开启。已有配置继续使用保存值；`enablePrediction` 控制启用，`predictionDistanceBlocks` 控制方块距离，`predictionSpyglassLoading` 控制望远镜额外加载，`rememberTerrain` 控制本地预测缓存。

## 远景如何加载

服务端真实列仍经过 VSS 请求、缓存、传输和解码，交给 Voxy 或 API 消费者。开启预测后，客户端 Rust / Java 根据同步的生成信息采样地形和完整植被，VSS 管理任务预算和缓存，再把体素交给 Voxy 构网、细化、遮挡与绘制。

预测覆盖使用 Voxy 渲染器，需要受支持的 Voxy 及其渲染环境。适配未就绪时等待恢复，不启用第二套独立预测渲染器。真实列在合成时优先，预测数据不会写入 Voxy 的真实持久缓存。

粗地形先提供覆盖，Voxy 根据当前画面触发细化。普通放大与望远镜都使用实际主画面投影，不依赖先命中远处地形；关闭望远镜额外加载后仍可放大观看已有数据。细化、植被和初始覆盖继续受 CPU、内存与并发预算控制。

`enablePrediction` 是预测总开关：关闭后撤回预测画面，真实远景保留；重新开启会复用仍在内存中的采样和映射缓存，并重新向 Voxy 发布。纯预测节点通过原生异步队列撤回，混合真实数据的节点按正常构网流程刷新，实际消失与恢复仍需经过 Voxy 的更新队列。`enablePredictionLoading` 只暂停新增预测加载，已有预测仍可显示。

开启预测时，真实远景区块生成与预测并行推进，不再等待预测进度达到 95%。生成仍受服务端配置与并发额度约束；单人真实生成和预测共享配置额度，不再根据整机 CPU 占用反复收缩。单人每玩家真实生成默认并发为 2，独立服务器仍为 4。

## 缓存与画面

预测缓存保存采样体素、完整植被、生物群系和精度信息；重进世界后恢复已有数据，由 Voxy 重新构网。光影切换可能让 Voxy 重建 GPU 资源，不等于重新计算全部地形。缓存身份以世界或服务器、维度和种子为基础，方块与生物群系按资源名称恢复。

已有精细、完整的记录优先于迟到的粗略结果。真实区块修改后先保留当前画面，等待最新真实列捕获与缓存提交完成，再局部刷新预测，避免先用旧数据重建。更改生成配置后，已缓存区域可能继续保留原预测。如需全部重新预测，应退出世界后清理对应维度的预测缓存，具体目录见 [缓存与排错](cache-and-troubleshooting.md)。

本次修复末地装饰的生物群系种子上下文，并按需重建旧末地装饰与成品 LOD 缓存。第一次读取旧区域时需要重新生成建筑与植被，原始地形和其他维度缓存继续复用，通常无需手动删除缓存。

植被密度过滤已移除。采样到的植物与地表结构完整发布，显示精度由 Voxy 处理。预测仍不等于完整生成真实区块；无法从同步生成信息重现的内容，以后来到达的真实列为准。

## Xaero 世界地图

Xaero 世界地图继续接收服务端真实远景列，可独立于 Voxy 使用。预测体素转换为地图的模块暂时停用；已有地图记录保留，真实列到达后仍可覆盖。不要把地图上的旧记录当作预测渲染或真实列已加载的证据。

## 更新后检查

保持原有光影测试主世界进入下界再返回、第二次进入存档、普通放大和望远镜。若旧进程已停在异常退出等待中，需要先关闭，再安装新包重启。0.3.6 修复了阴影空视口触发的异常；其他模组的退出锁等待需要按实际日志另行判断。

`/vssclient stats details` 可查看世界生成档案、瓦片、队列和预测数据状态。自动回归检查不创建实际游戏画面，最终视觉、帧率和整合包组合仍需实机确认。
