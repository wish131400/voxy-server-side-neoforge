# 远景抗混叠（0.3.2 后续修复）

## 范围与使用

针对 2026-09-21 22-16-29 视频中雪坡台阶、覆雪树冠的密集高反差边缘。
无光影、开启预测且已有预测网格时，默认启用一次远景方向性 FXAA。
在 VSS 预测设置里切换“远景抗锯齿”，或设置客户端 `predictionAntialiasing`。
开关仅控制屏幕后处理；雪面合并及预测图集过滤始终生效。

普通渲染共享最终世界画面，过滤同时作用于实际区块、Voxy 和预测。
在 AFTER_LEVEL、HUD 绘制前执行，基于深度与投影算出屏幕上的方块大小：
每像素覆盖 0.15～0.65 方块时平滑加强处理，近处及放大后的细节自动保留。
天空不处理；轮廓检测跳过低对比区域。无历史帧、随机透明抖动、运动矢量或独立 TAA。
本版是方向性 FXAA 加亚像素平行细线处理，不是 SMAA 或 TAA，不能承诺完全消除所有移动闪烁。

开启 Iris/Oculus 光影时不叠加该后处理，沿用光影自身的抗锯齿。
预测图集过滤和雪面合并仍然有效，但光影下 Voxy/真实区块的几何锯齿需由光影处理。

## 源头优化

- 在网格构建时合并同高度、同状态的薄雪顶面，裁掉被相邻雪层遮挡的内部侧面。
  合并限制在同一个覆盖单元内，保留高度差、空洞、外轮廓和细分交接。
  已有矩形合并器继续合并外侧面；测试中的 8×8 单层雪最终为 5 个四边形。
- 不在逐帧渲染中重算雪面，不更改磁盘记录，不重新生成树木或改写 Voxy 数据。
- 预测 atlas 使用独立 sampler，缩小时双线性/三线性过滤，有扩展支持时最多 4× 各向异性。
  放大仍用 nearest 保留方块像素风；没有 mipmap 时不用 mipmap sampler。
  不更改 Minecraft/Voxy 共享图集的纹理参数，绘制结束恢复原 sampler。

## 后处理与资源

复制一次世界颜色到 RGBA8 纹理，再进行一个全屏绘制。
输出到仅含主颜色纹理的 FBO，采样主深度而不将它挂在输出 FBO 上，避免读写反馈。
不改变深度、颜色 alpha 或透明材质属性。恢复 framebuffer、viewport、sampler、blend、
depth、cull、scissor、stencil 和颜色写入掩码。尺寸变化复用对象并调整存储。
关闭开关/预测、启用光影或世界重置时，在渲染线程释放后处理资源。

新增颜色纹理：1080p 约 7.91 MiB，4K 约 31.64 MiB；没有多帧历史图。
调试计时新增 `ANTIALIAS` 阶段，用于换包后的实际游戏测量。

## 验证

RTX 4070 Ti SUPER 独立 OpenGL 测试，平行高反差细线场景，包含颜色复制与过滤：

| 分辨率 | GPU 中位耗时 | 约第 93 百分位 |
| --- | --- | --- |
| 1920×1080 | 0.061 ms | 0.062 ms |
| 3840×2160 | 0.221～0.222 ms | 0.223～0.228 ms |

这是合成场景 GPU 数据，不是实机 FPS 提升/损失保证，也不代表 CPU 驱动调用成本。

像素测试要求细线对比下降，同时近处、望远镜、天空保持精确像素；深度和 alpha 不变。
覆盖调整窗口尺寸、外部 sampler/掩码恢复、共享 atlas 参数不被污染。
雪面测试比较合并前后的精确覆盖集合、高度、空洞、覆盖单元边界，以及生产网格输出。
既有 GPU 回归继续覆盖冰水交接、接缝、光影状态恢复、远距离与望远镜深度。

最终效果需在新 JAR、同一世界位置开关对照；不以测试图冒充游戏换包后的截图。
