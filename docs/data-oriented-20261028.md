# 预测数据布局与转换开销优化

适用于 VSS 0.3.6 的 NeoForge 1.21.1 与 Forge 1.20.1，构建标识 `data-oriented-20261028`。

本次集中处理预测加载过程中的状态索引、重复计算和临时对象分配。Rust / Java 继续完成采样，Voxy 继续负责构网和绘制。

- 瓦片的 11 类生命周期标记和 5 类时间戳共享一个身份索引，使用分页位图与原始数值数组保存。各状态独立清理，旧工作快照保持不可变，释放的槽位可复用。
- 调度和加载统计在同一份输入内复用瓦片状态、距离与投影计算。缓存恢复和内存回收先计算排序值，比较器直接比较这些值。近处优先、远处公平调度、失败重试与实际任务准入保持原有行为。
- 植被显示中间数据使用完整坐标数组和方块状态调色板，正常显示直接遍历原始数据；兼容读取需要时才生成逐格列表。按格分桶后排序，避免每次比较都重新计算格坐标。
- 材质映射与地形段材质数组在工作线程内复用，每次转换结束清除方块、群系和映射器引用。复杂区段压缩复用有界的整数边界缓冲，减少扫描；不额外保留完整展开区段。
- 变化通知复用六面缓冲，并保留方块、子节点占用和邻接面的内容比较。并发与嵌套调用使用独立工作区，异常退出时也归还工作区。

回归检查覆盖完整植被内容、来源重叠、真实列捕获、液体和生物群系、精度与调度顺序、并发回收、维度生命周期和 Voxy 后端入口。本次同时保留父层显示合成、相同内容去重、大型植被分页缓存和低内存收敛修复。

离线回放中，65,536 个植被方块的显示构造分配从约 10.90 MB 降到 3.03 MB；该数字来自线程分配计数，并非整个游戏的内存占用。局部转换耗时会随运行负载变化，应参考随包验证记录中的实际结果。

本次不改变预测距离、植被数量或采样精度。离线回放和自动回归不能换算成游戏 FPS；整机帧率、跑图加载速度和内存峰值需要替换该构建后在相同场景测量。
