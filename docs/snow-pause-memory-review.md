# 雪地材质、暂停降耗与内存审查（2026-09-22）

> 阶段记录：正文中的实验范围、未提交状态和测试数字对应当时的工作节点。0.3.2 之后截至本次提交的最终功能与升级说明见 [更新日志](../CHANGELOG.md)。

雪地侧壁有两条错误路径：地形墙使用草方块默认状态；装饰方块虽然保留 snowy=true，但颜色按方块类型而非所选烘焙面的染色标记处理。原版 grass_block_snow 模型继承 cube_bottom_top，不带 tintindex。现在缓存每个状态/面的染色标记，并在地形墙、LOD 接缝、真实区块接缝的顶层使用覆雪状态，地下泥土与岩石层不变。完成网格缓存版本从 2 提升为 3，样本缓存仍有效。

新增 predictionPausedFps，默认 30，0 关闭。仅预测开启、有世界且 Minecraft.isPaused() 为真时应用；通过 Minecraft.getFramerateLimit 返回值限制整个场景的重绘频率，不隐藏远景，不修改用户保存的帧率设置。已有更低上限予以保留。多人游戏普通菜单不是真正暂停。

后续内存优化优先考虑非活跃 CPU 网格的无损压缩/按需恢复，随后评估接缝墙编码；须同时覆盖 GPU 重新上传、资源重载、磁盘写入与过渡回退。该轮未实施内存存储重构，未测得压缩收益。
