# 2026-10-06 预测植被三档与望远镜加载开关

## 行为与默认值

两个加载器继续发布 0.3.5，新增客户端设置：

| 设置 | 默认值 | 行为 |
| --- | --- | --- |
| `predictionVegetationDensity` | `medium` | `low` 约 25%、`medium` 约 50%、`high` 100% 的预测植被 |
| `predictionSpyglassLoading` | `true` | 是否允许望远镜目标额外触发远处地形、植被及建筑细化 |

VSS 预测设置页的植被选项由开关改为三档；Forge 使用 Embeddium 三档循环控件，NeoForge 适配旧 Sodium 的循环控件和 Sodium 0.8 的三个离散值。中英文标签显示档位与比例。望远镜远处加载是独立开关，关闭后仍可缩放观看已经加载的远景。

旧 JSON 没有新档位字段时，`predictionTrees=true` 迁移为中档、`false` 迁移为低档。已有明确档位及望远镜开关保留。旧布尔字段只为配置迁移与兼容保留，设置界面不再显示它。

## 稳定显示选择

完整来源区块的原始植被 Map 先做密度选择，再裁剪到显示瓦片和进行 voxel 简化。普通小植物按世界 X/Z 整柱选择，高草与竹子等上下段一致；树干与相连树冠按完整连通组选择，同一来源树组跨显示瓦片使用相同决定。低档是中档的子集，中档是高档的子集。选择不依赖相机位置或帧号。

未确认有树干、树冠，或连接木板、楼梯、台阶、门、栅栏等建筑组件的木质组保守保留。地形切割、空气、雪和流体保留。只改变预测显示，原始地表生成结果、城市模板和真实区块不被密度选择修改。

连在一起的树冠按整组处理，保护性的模板木质保留也会影响计数，因此场景中的实际比例近似；高档保留密度选择前的全部结果。此前的距离显示 LOD、模型简化及可见性筛选仍会进一步影响最终绘制数量。

简化植被代表也按完整 Form 选择并重新计算 bounds；森林颜色的覆盖权重随密度缩放。此设置减少显示几何数量，原始地表生成仍可执行完整放置，不能将比例直接理解为等量减少世界生成 CPU。

## 缓存与任务生命周期

成品网格身份包含密度档位；仅修改密度时复用地表生成上下文和原始植被缓存。切换触发 revision 和后台网格更新，旧任务经过取消检查后退出，已有显示逐步由新版网格替换，无需删除预测缓存。

来源密度选择缓存按原始 Map 身份、来源区块、密度和注册表标签 generation 区分，使用弱引用跟踪原始来源，限制为 128 项 / 8 MiB；显示瓦片缓存原有 64 项 / 16 MiB 上限保留。局部来源变化或标签重新加载会重新选择。

关闭望远镜加载后，客户端清除目标并阻止异步选点回调恢复旧目标；TileManager 忽略 focus，并让尚未完成的 scope 任务在下个阶段取消检查点退出。普通加载继续运行，关闭动作无需清除已有精细缓存。
