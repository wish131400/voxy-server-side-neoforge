# 飞行 / 冲刺视角水面交接黑缝修复（2026-10-06）

## 问题与证据
用户视频在高空面向预测 LOD 与 Voxy 水面边界时出现随视角变化的深色接缝。当前客户端为 NeoForge 1.21.1，Voxy 0.2.15-beta。
已读取视频和截图，并核对安装包内预测渲染类与上一轮缓存修复包一致。
在实际 GPU 上构造同面水交接回归：90 度 FOV、高度 179、俯角 0.7 弧度时，修复前中央 2304 像素中有 144 个像素错误绘制预测水。
这验证了能产生重复水面混合变暗的渲染错误；尚未取得此现场的分阶段捕获，不将全部实景黑线都判定为已确认的同一原因。

## 修复
生产修改集中于 PredictionTerrainProgram.java：
- 大型水面三角形经过近裁剪后，倒数 W 插值误差可超过原有同面容差。对平面水使用逆 MVP 与真实面方程求交，求出该像素的 clip-W；CPU 用双精度求逆后上传矩阵。
- 原版主深度 D24 在远裁剪范围内同样可能不能区分相邻水深。水面在主深度与 Voxy 最终合成深度匹配时借用 Voxy 原始深度，不再仅在主深度饱和时借用。
- 保留更近的原版前景遮挡；主深度为空时不允许尚未合成的 Voxy 深度抹掉预测补位。
- 水面不参与地形形变，因此即使沿用非零地形形变参数，平面水仍可使用精确平面计算。

未增加绘制批次或生成限流，未修改缓存格式。保留原地形早期深度测试及原有同面容差。水片元增加求交计算；本轮没有进行运行中客户端 FPS 对比，不能承诺性能增益。

## 验证
NeoForge 与 Forge 各 12 项 JUnit 测试通过，0 失败、0 跳过，assemble 成功。主要 GPU 测试内部包含大量场景组合：
- FOV 1 / 7 / 70 / 90 度；多种高度；原版远裁剪 320 / 2048。
- 普通 / 反向深度及两种深度约定。
- 90 度、高度 179 下的视角平移、旋转组合。
- 同面真实水优先；低于预测面的背景保留预测水；更近原版前景仍遮挡；主深度空白时保留补位。
- 原有 Iris、深度重置、实例化、遮挡等回归。

运动测试使用两个反投影点求射线与水面交点，避免错误假设平移后的相机射线仍从零点出发。
GPU 为 RTX 4070 Ti SUPER。Voxy 深度合成兼容性测试使用当前 Neo 客户端安装的 Voxy shader，不能替代 Forge 整合包现场验证。
两仓库生产源文件一致；git diff --check 通过；Neo 包内修改类与隔离构建输出一致；两包均包含新 shader 且无临时调试 shader，保留此前预生成缓存功能。
