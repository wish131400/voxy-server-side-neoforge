## 已接通的计算

原版随机、噪声、密度图与插值、基础高度和液体柱、含水层、地表规则、坏地与冰山、三维生物群系查询、草叶水颜色、受支持的树/草/花/竹子放置都通过 JNI ABI 2 在 Rust 执行。Java 导出实际注册表、方块属性、支撑面和颜色图，继续负责 Minecraft 模型、纹理、网格与 GPU。

植被执行原版全局顺序、seed 和放置修饰器；树生成还包括树苗生存、树叶距离、双侧边缘方块更新及装饰物。原生与 Java 兼容步骤按顺序同步编辑，原生失败时回滚方块和随机状态。缓存具有独立算法身份，继续使用现有存档/服务器隔离路径。常规诊断细节受 `debugLogging` 控制；游戏内 `/vssclient prediction` 可查看 `backend=vanilla-rust-abi2-r1`、`nativeFeatures` 和 `compatibilityFeatures`。

## 已运行验证

- 全部 Rust release 测试通过：97,440 随机/噪声比较、56,014 噪声依赖比较、22,725 密度值、21,120 基础柱方块、3,030 生物群系/zoom、15,360 颜色/温度比较。
- 42 组原版地表案例（3,604,480 方块）、400 次稀疏/完整地表查询一致。
- 261 组 configured 植被、171 组 placed 植被、9 组受控独立随机熵的蜂巢案例通过；包含完整黑森林和蘑菇岛的选择链。
- 33,235 个显式结构地形调整数值一致。
- JNI 参数、缓冲区、关闭/租约、取消、资源颜色图更新和编辑事务通过；生产链 560 组网格/材质/颜色检查及 7 组混合植被任务通过，含实际热带草原、针叶林和黑森林放置链。
- Java/GPU 共 516 项测试，失败/错误/跳过均为 0；GPU 为 NVIDIA GeForce RTX 4070 Ti SUPER。
- `PredictionVanillaMask` 编译字节码与保留的基线一致。

Gaussian 在本机最大误差 1 ULP，单独允许 4 ULP 的平台数学舍入界；不将其写成所有随机计算逐位一致。

日志：`build/rust-worldgen-final-validation.log`、`build/rust-worldgen-delivery-validation.log`。

## 性能及边界

完整生产输入包含 26,684 个方块状态。本次离线测得：冷启动基础/地表区块约 103–119 ms，64 个远处稀疏点 109.67 ms，冷启动 5×5 地表上下文 2488.90 ms，已有列缓存时重建该上下文 4.69 ms。原生方块数组占 9,830,400 字节，不含其他对象。日志为 `build/rust-worldgen-production-benchmark.log`。这不是游戏帧时间测试，也不代表第一次生成不再有成本。

这仍是地表预测后端。完整结构起点/引用/jigsaw、carvers、全部装饰阶段和模组钩子未全部移植；道路、农田和结构编辑继续由现有 Java 路径提供。未知模组的 feature 和方块钩子保留兼容执行。Beardifier 数值已移植，但生产自动结构上下文尚未接通。原版对照采用对应阶段的真实方法和运行时输入，存档采集仅作辅助；不宣称完整最终世界已逐块一致。

新库已构建执行的平台为 Windows x86_64，其余平台保留原有兼容后端。本次产物写入工作区，未替换游戏目录中的模组文件。
