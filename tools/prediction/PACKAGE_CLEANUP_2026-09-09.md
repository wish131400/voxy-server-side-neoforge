# 原生后端、无用代码与 JAR 体积清理

本轮从已完成精细化减负的 0.3 包开始审查。旧原生后端仍存在备用调用路径，
但不被当前 Rust 后端依赖。已移除旧路径，当前选择为：自定义兼容适配器、
本项目 Rust 核心、Java 回退。新 Rust 原生包目前只覆盖 Windows x86_64；
其他系统使用 Java，不能把旧平台二进制当作新核心的跨平台构建。

不等于游戏运行内存按同样比例下降。新 Rust DLL 原始大小为 1,106,432 字节。
JAR 中没有 Rust 源码、测试夹具、Cargo target、离线工具或存档预测缓存。

## 已清理的代码与资源

- 五个旧平台二进制，以及旧采样器、JNI 桥接、动态 JNI 声明生成器。
- 旧后端回退入口、统计和关闭分支，以及旧方形批次适配。
- `RustWorldgenSnapshot` 及未接入生产的 Rust 早期快照解析、32 字节柱结构、
  LOD 选择、四边形打包、法线和占水裁剪原型。生产中的对应功能继续使用
  已接入的 JNI 数据格式和 Java 渲染实现。
- 没有生产引用的 `VssLodPalette`、`VssLodOcclusion`，以及没有 Mixin 注册的
  `PlayerRespawnNoBlockingMixin`。实际模组入口 `VSSMod` 通过注解加载，保留。
- 旧二进制重放工具、对应 Gradle 任务、三个旧测试文件及失效的测试方法。
- 重复的 `assets/vss/icon.png`；模组元数据引用的根目录 `icon.png` 保留。
- 旧结构注册表侧附字段，以及项目源码、说明文档和包内许可文件中的旧项目引用。

共删除 17 个文件，其中 7 个为生产 Java 类，5 个为旧二进制；其余为旧测试、
重放工具与重复图标。当前 JNI ABI 2、独立噪声验证接口、Java 自定义 feature
回退、资源包模型和 GPU 管理仍有实际用途，保留。

生产源码净减少 1,253 行。对 Java/Rust 文件执行内容哈希，以及去除注释行、
包名/导入行并归一化空白后的连续 16 行、超过 700 字符片段扫描，未发现
完全重复文件或满足该阈值的跨文件重复片段。最终 JAR 中没有重复内容文件。
这类检查不证明所有语义相似逻辑都已合并；此次没有以删除仍有调用的兼容
路径或大规模重构代替无用代码清理。

## 采集工具迁移

`/vssclient prediction capture` 现在直接采集 Minecraft Java 数据，格式为
`vss-rust-reference-2`，不加载原生库。保留地表记录、原版噪声/密度/基础柱、
植被、随机序列、方块状态与资源数据；不再输出旧二进制专用记录和索引表。
元数据明确记录 Java 来源。

实际离线 plains 采集完成并通过校验：64 条地表记录、192 条密度记录、
32 条噪声记录、16 条基础柱、4 条随机序列和 4 个植被区块。
历史格式 1 的一个真实存档采集副本也通过校验。保留旧格式的文件解码能力，
不需要旧二进制；原存档没有修改。
