# Voxy 0.2.15 prediction shader handoff

## Evidence and changes

The user's screenshots show normal prediction without shaders and absent opaque
prediction with Complementary Unbound r5.8.1. The 11:18 session log reports a
successfully installed prediction profile, built terrain and an active Voxy Iris
pipeline, without a prediction shader exception.

Inspection of the installed Voxy 0.2.15-beta class shows that
`postOpaquePreTranslucent(Viewport)` became
`postOpaquePreTranslucent(Viewport, int)`. The optional old Mixin did not match,
so the opaque prediction draw never ran. A second injection now handles the
new signature immediately before the opaque-to-translucent framebuffer blit,
after Voxy's shader-depth repair. The old signature remains supported.

The prediction depth comparison now distinguishes clear sky using the active
depth convention. Standard Z uses clear depth 1; reverse Z uses 0. Finite far
planes must not cause the empty sky depth to hide coarse predicted surfaces.

## Additional initialization regression

During this work the user restarted with the preceding Tectonic fix. The 11:28
log and installed JAR hash confirm that it removed the HolderHolder failure but
then hit `VSS generator snapshot exceeds size limits`. The applied graph had
expanded shared density subgraphs, exceeding the 8 MiB raw generator budget.

Snapshots now intern repeated nodes as Minecraft density registry references.
Only known holder-codec fields are substituted; Clamp.input and unknown custom
codec fields stay inline. Noise settings and registry entries share definitions
across dimensions. Normal noise registry identities and packet limits remain
unchanged. Temporary applied-graph construction still occurs during the cached
worldgen snapshot build; this change does not claim to eliminate that cost.

## Verification

- 532 tests passed, zero skipped or failed.
- ASM inspection of the installed Voxy JAR verifies exactly one matching opaque
  callback and that its new anchor follows depth repair and precedes the copy.
- GPU tests executed on NVIDIA GeForce RTX 4070 Ti SUPER: actual production
  prediction shaders, both clip ranges, standard/reverse Z, sky fill, foreground
  occlusion, water, texture sampling, MRT/TAA interface and state restoration.
- Regression graph exceeds 8 MiB inline; shared definitions plus root occupy
  less than 16 KiB and preserve decoded sample values. Actual installed Tectonic
  and Lithostitched function-class tests also pass.

GPU tests use a controlled Voxy fragment adapter, not the fully preprocessed
Complementary shader pack. The complete user's game, resource-pack and shader
combination has not been visually verified after the fix. The Iris warnings
about newer-game-version uniforms are separate from the missing opaque hook;
this patch does not alter shader-pack files or Iris configuration.
